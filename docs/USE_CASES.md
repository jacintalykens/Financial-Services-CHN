# 11 个典型使用场景速查

每个场景对应一个或多个 skill，按用户类型分类。

## 散户投资者

### 1. 看不懂研报真假
**场景**：朋友发来一份研报推荐某只股票，想验证可信度。
**触发**：earnings-analysis-cn + audit-xls-cn
**输出**：研报数据自检 + 数字一致性检查 + A 股地雷扫描

### 2. 海量公告淹没关键信息
**场景**：关注 50 只 A 股，每天有几百份公告看不过来。
**触发**：announcement-digest-cn
**输出**：自动筛选 + 利好利空判定 + 6 段式摘要

### 3. 宏观数据公布后看不懂
**场景**：PMI 出炉，不知道对自己持仓的影响。
**触发**：macro-alert-cn
**输出**：异动判定 + 4 类资产传导路径 + 历史相似情境

### 4. 想自己分析公司
**场景**：想深入了解一只关注的股票。
**触发**：initiating-coverage-cn（深度）or earnings-analysis-cn（点评）
**输出**：30-50 页深度报告 or 8-14 页业绩点评

### 5. 估值是否合理
**场景**：股价涨了 40%，估值还合理吗？
**触发**：comps-cn + dcf-cn 双锚交叉验证
**输出**：可比公司估值矩阵 + DCF 内在价值 + 双锚目标价

## 散户 / 个人理财客户

### 6. 买基金 / 信托不懂合同
**场景**：销售人员推荐了一只私募，合同 50 页看不懂。
**触发**：contract-devil-clause-cn
**输出**：8 大维度审查 + 🔴🟡✅ 分级条款 + 白话翻译 + 协商建议

## 中小机构

### 7. 没钱养完整研究 + 合规中台
**场景**：中小券商资管想替代部分自建研究 / 律所合规咨询。
**触发**：组合使用 11 个 skill
**输出**：替代部分研究 + 合规中后台功能

### 8. 监管法规变化漏接
**场景**：合规岗想跟踪监管法规变化。
**触发**：compliance-watcher-cn（Push 模式）
**输出**：每日法规追踪日报 + 影响业务场景标签

### 9. 新产品发行前合规自查
**场景**：理财子准备发行新产品，需在律所审查前自查一遍。
**触发**：compliance-watcher-cn（Pull 模式）
**输出**：A/B/C/D 合规评分 + 🔴/🟡/✅ 分级条款 + 修改建议

## 出海企业

### 10. 收到海外监管函看不懂
**场景**：公司收到 SEC / FCA / SFC 监管函，措辞紧急但看不懂。
**触发**：cross-border-compliance-cn
**输出**：双语对照精准翻译 + 紧急度判定 + 行动清单

## 研究员 / 实习生

### 11. 不会做行业研究 / 首次覆盖
**场景**：新入职研究员，不知道行业研究 / 首次覆盖怎么写。
**触发**：sector-overview-cn + initiating-coverage-cn
**输出**：行业研究 20-30 页 + 首次覆盖 30-50 页（按券商标准模板）

## 技能组合套餐

### 套餐 A：散户研究升级（最常用）
- earnings-analysis-cn（业绩点评）
- announcement-digest-cn（公告精读）
- comps-cn + dcf-cn（估值核验）
- 用于：散户自主研究单只股票全流程

### 套餐 B：中小机构合规中台
- compliance-watcher-cn（法规追踪 + 合规审查）
- audit-xls-cn（研报与模型质检）
- contract-devil-clause-cn（合同审查）
- 用于：替代部分律所合规咨询

### 套餐 C：出海企业法务工具箱
- cross-border-compliance-cn（跨境监管翻译）
- compliance-watcher-cn（国内合规对照）
- 用于：出海企业法务部日常工具

### 套餐 D：研究新人学习套件
- sector-overview-cn（行业研究方法论）
- initiating-coverage-cn（首次覆盖方法论）
- earnings-analysis-cn（业绩点评方法论）
- comps-cn / dcf-cn（估值方法论）
- 用于：研究员 / 实习生学习卖方研究全流程

## 协同流程示例

### 示例 1：完整公司研究流程

```
1. macro-alert-cn 看宏观环境
   ↓
2. sector-overview-cn 看行业景气
   ↓
3. initiating-coverage-cn 做首次覆盖（含 DCF + Comps 双锚）
   ↓ （后续季度跟踪）
4. earnings-analysis-cn 业绩点评
   ↓
5. announcement-digest-cn 公告跟踪
   ↓
6. audit-xls-cn + compliance-watcher-cn 输出前质检
```

### 示例 2：散户买基金前流程

```
1. contract-devil-clause-cn 审查合同
   ↓
2. 如有问题：用建议协商点回去找销售商谈
   ↓
3. 协商成功 → 签字
   或协商失败 → 不买
```

### 示例 3：出海企业收到监管函

```
1. cross-border-compliance-cn 翻译 + 紧急度判定
   ↓
2. 🔴 极紧急 → 24 小时内联系当地律师
   🟡 紧急 → 1 周内启动律师评审
   ⚪ 普通 → 30 天内回复
   ⚫ 信息性 → 内部合规更新
   ↓
3. compliance-watcher-cn 评估对国内业务的连带影响
```

## 不构成投资建议

所有 11 个技能均**不提供**：
- 个股买卖建议（评级仅做"分析结果"，不构成"操作指引"）
- 法律意见（合同审查 / 跨境合规仅供参考，须咨询持牌律师）
- 货币政策预测（宏观异动仅做情景推演）

复杂场景请咨询持牌专业人士（券商分析师 / 律师 / 投资顾问）。
