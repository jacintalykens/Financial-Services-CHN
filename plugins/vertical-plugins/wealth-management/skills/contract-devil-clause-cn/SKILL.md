# 中国资管产品合同魔鬼条款审查规范 (Devil Clause Review for China Asset Management Contracts)

为散户、个人投资者、家族办公室、中小机构客户构建的**资管合同风险审查工具**。解决"私募 / 信托 / 银行理财合同动辄 50-200 页，投资者在不充分理解条款的情况下签字，事后发现关键条款对自己极不利"的痛点。

**人机协作模式**：A. 起草-审核 —— AI 通读合同 → 识别 8 大维度风险条款 → 输出分级清单 → 人确认风险偏好后做协商决策。

**核心特征：**

- **覆盖产品类型**：私募投资基金 / 信托资金计划 / 银行理财（净值型 + 固收类）/ 券商资管 / 基金专户
- **响应时效**：通常 30-90 分钟（合同长度 50-200 页）
- **目标用户**：散户、家族办公室、企业理财、私募 LP、信托受益人
- **输出形式**：Markdown 审查报告
- **保密原则**：**不存储用户合同**，仅会话期处理
- **合规底线**：声明"仅供参考，不构成法律意见"；建议复杂情形咨询持牌律师

## 触发场景 (When to Use)

**适用场景：**

- "帮我看看这份私募基金合同有什么风险条款"
- "信托计划合同审查"
- "购买这只银行理财产品前帮我读说明书"
- "券商资管 / 基金专户合同条款分析"
- "比较两份私募合同的差异性条款"
- "管理人协议里有什么对 LP 不利的条款"

**严禁使用本技能的场景：**

- **保险合同** → 性质不同，触发保险专用审查（如适用）
- **股权投资协议**（SPA / 增资协议 / 对赌协议） → 触发股权投资合同审查模板
- **借款合同 / 借据 / 借贷协议** → 触发借贷合同审查
- **境外资管产品**（开曼基金 / SPV / 私人银行账户协议） → 触发跨境资管合同模板
- **公司商业合同**（采购 / 销售 / 服务） → 触发商业合同审查
- **劳动合同 / 不动产合同** → 不适用
- 用户上传非合同原文（如个人理财方案 / 营销材料）→ 拒绝，要求提供完整合同文本

## 核心执行要求

### 1. 8 大审查维度 ⭐ 强制全覆盖

每份合同必须按以下 8 大维度逐条审查，每维度输出 🔴/🟡/✅ 分级结果：

#### 维度 1：费用条款审查（最常见陷阱）

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 管理费费率 | 1.0-1.5% 年化（主流私募）；信托 1.5-2.5%；银行理财 0.2-0.8% | 管理费 >2.5% 私募 / >3% 信托 |
| 管理费起算时点 | 资金到账 T+1 起算 | 募集开放期起算（即未实际投资也收费） |
| 业绩报酬比例 | 20% 主流（私募 / 信托） | >25% 或"前 X% 也提取业绩报酬"（投资者只拿超额收益的极小部分） |
| **业绩报酬基准** | 通常无风险利率（如 1 年期国债） | "0%"基准（任何正收益都提业绩报酬） |
| **高水位线（High-Water Mark）** | 必须有，且为累计高点 | 无高水位线 / 高水位线每年重置（管理人可重复提取业绩报酬） |
| **回拨条款（Clawback Provision）** | 客户要求设置；如基金后期亏损，可追回前期业绩报酬 | 无回拨条款 |
| 申购费 | 1.0-1.5% 主流；银行理财 0-0.6% | >2% 申购费且无理由 |
| 赎回费 | 0-0.5%（持有 1 年以上免赎回费） | 短期赎回 ≥3%（迫使长期持有） |
| 托管费 / 咨询费 / 其他费用 | 0.1-0.3% | 列出"其他费用，金额由管理人决定"等模糊条款 |
| 费用包含税费？ | 必须明确 | "不含税"且税率不固定 |

**示例**（🔴 严重不利）：
> "管理人对每个 Subscription Date 的资金独立计算业绩报酬，无高水位线机制，每自然年度独立计提。"
> **白话翻译**："你今年赚 100 万分给管理人 20 万，明年亏 80 万后管理人不退钱。下一年再赚 20 万管理人又拿走 4 万。这是反复提业绩报酬。"

#### 维度 2：赎回与清盘条款

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 开放期频次 | 月度 / 季度（私募） | 仅年度开放（流动性极差） |
| 开放期窗口 | 通常 5-10 个工作日 | <3 个工作日（投资者抢时间难） |
| 锁定期 | 6-12 月（主流） | >2 年 锁定 |
| 临时关闭赎回的条款 | 应限定极端情形（市场流动性危机） | 管理人可"自行决定"关闭赎回 |
| 巨额赎回 | 触发条件 >10% 或单日 ≥5% | 触发条件 <5% 即可启动延期 |
| 清盘触发条件 | 净值跌至 0.7 等明确数字 | 无明确清盘线（管理人可任意决定） |
| 强制清盘的程序 | 应有 LP / 投资者投票 | 管理人单方决定 |
| 清盘后清算费用 | 不超过 1% | 高额清算费由 LP 承担 |

#### 维度 3：投资范围与关联交易

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 投资范围明确 | 列明具体资产类别 + 比例 | 投资范围模糊（"管理人决定的金融工具"） |
| 关联交易约束 | 必须公允定价；超 5% 需 LP 通过 | 无关联交易约束（管理人可与自己关联方交易） |
| 单笔最大投资比例 | 通常 ≤ 10-20% | 无限制或单笔可超 50%（集中度风险） |
| 杠杆使用 | 资管新规规定 ≤140%（开放式）/200%（封闭式） | 突破监管杠杆上限 |
| 衍生品使用 | 应明确允许品种 + 用途（对冲 / 投机） | 无限制使用衍生品 |
| 投资标的范围变更 | 应需 LP 大会通过 | 管理人单方变更 |

#### 维度 4：信息披露义务

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 净值披露频次 | 月度（私募）/ 周度（银行理财） | 季度甚至年度披露 |
| 投资明细披露 | 主要持仓 + 行业分布 | 不披露任何持仓信息 |
| 业绩报酬计提透明度 | 应有详细计算公式 | 仅文字描述，无公式 |
| 季度 / 年度报告 | 完整报告 + 审计 | 仅汇总数据，无审计 |
| 重大事项披露 | T+3 日内 | 无明确时限 |
| 投资者咨询权 | 应有 | "管理人有权拒绝回答" |

#### 维度 5：合同变更与终止

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 合同变更方式 | 须 LP 大会 2/3 通过 | 管理人单方变更（不利） |
| 管理人变更 | LP 投票 + 接管人选定 | 管理人辞任后无明确替代机制 |
| 合同提前终止条件 | 限定情形（如基金达到上限） | "管理人可随时终止"（不利） |
| 提前终止补偿 | 应有 | 无补偿（投资者完全承担） |

#### 维度 6：不可抗力与免责

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 不可抗力定义 | 明确 + 限定 | 宽泛定义（"任何无法预见情形"） |
| 管理人免责范围 | 故意 / 重大过失外免责 | 任何过失都免责（包括重大过失） |
| 投资风险揭示 | 应充分 + 醒目 | 仅一行模糊文字 |

#### 维度 7：争议解决地点 ⭐ A 股本土陷阱

| 子项 | 标准 | 🔴 不利信号 |
| :--- | :--- | :--- |
| 仲裁 vs 诉讼 | 通常仲裁 | — |
| 仲裁地 | 应在投资者所在城市或北京 / 上海 | 仲裁地为偏远城市（如管理人注册地） |
| 仲裁机构 | 知名机构（北仲 / 上仲 / 贸仲） | 偏远地区仲裁委（程序成本高） |
| 适用法律 | 中国法律 | 境外法律（投资者维权门槛极高） |

#### 维度 8：对投资者最不利的条款

需特别识别以下高危条款：

| 条款类型 | 示例 | 风险 |
| :--- | :--- | :--- |
| **预期收益与实际收益脱钩** | "宣传预期收益 8%，合同写'非保本浮动收益'" | 投资者误认为保本 |
| **赎回排队 / 排队赎回** | "赎回按申请时间排队，每月额度有限" | 流动性陷阱 |
| **业绩报酬"假高水位线"** | "高水位线 = 业绩报酬计提期间内最高净值" | 名义高水位实际可重提 |
| **管理人单方决定权过大** | "投资策略变更 / 杠杆使用 / 关联交易 由管理人自行决定" | 管理人滥用裁量权 |
| **风险等级 vs 实际投资不符** | "R3 中等风险等级合同，但投资标的含 R5 衍生品" | 适当性义务违反 |

### 2. 风险分级标准（🔴/🟡/✅）

#### 🔴 严重不利（必改 / 不建议签）
- 违反监管硬性规定（如资管新规杠杆上限）
- 直接侵害投资者核心权益（如无高水位线 + 无回拨）
- 信息严重不透明（如不披露任何持仓）
- 单方变更权过大

#### 🟡 风险（建议协商）
- 偏离主流标准但未违法
- 部分条款可解读为对投资者不利
- 信息披露频次低于主流
- 锁定期偏长

#### ✅ 标准
- 符合主流标准
- 监管合规

### 3. 白话翻译规范（散户友好性核心）

每个 🔴/🟡 条款必须配**白话翻译**：

```
原文（合同）：
"管理人对每个 Subscription Date 的资金独立计算业绩报酬，无高水位线机制，每自然年度独立计提"

白话翻译：
"管理人是这样收业绩奖金的：
1. 你今年赚 100 万，管理人拿走 20 万（业绩报酬 20%）
2. 明年亏 80 万，管理人不退之前拿走的 20 万
3. 后年再赚 20 万，管理人又拿走 4 万
→ 累计 2 年你净亏 20 万，但管理人拿了 24 万。
这种条款叫'无高水位线'，对你很不利。
主流私募应该是：你的累计净值要超过历史最高点后，管理人才能再次提业绩报酬。"
```

### 4. 建议协商点（散户实战指南）

每个 🔴/🟡 条款必须给"建议协商点"：

```
建议协商点：
1. 要求增加"累计高水位线"条款
2. 要求增加 3 年回拨条款（基金清盘时业绩报酬若超过实际收益的 20%，需退回）
3. 业绩报酬基准应不低于 1 年期国债收益率
4. 如管理人拒绝以上修改，建议不购买该产品
```

### 5. A 股本土法规对照 ⭐ 强制引用

每条审查结果必须引用中国监管法规依据：

| 法规名称 | 关键条款 | 引用场景 |
| :--- | :--- | :--- |
| 《证券投资基金法》 | 公募 / 私募基金基础规则 | 全部 |
| 《私募投资基金募集行为管理办法》（中基协） | 募集流程 / 适当性义务 / 信息披露 | 私募基金合同 |
| 《资管新规》（2018，中国人民银行等四部门） | 杠杆上限 / 非保本浮动收益 / 净值化 | 私募 / 信托 / 资管 |
| 《信托公司集合资金信托计划管理办法》 | 信托产品基础规则 | 信托合同 |
| 《商业银行理财业务监督管理办法》 | 银行理财净值化要求 | 银行理财说明书 |
| 《适当性义务》（证监会 + 中基协） | 风险评级匹配 | 风险等级审查 |
| 《消费者权益保护法》 | 通用消费者权益 | 银行理财通用条款 |

### 6. 保密与合规底线 ⭐⭐⭐【硬性强制】

#### 6.1 保密原则
- **不存储**用户上传的合同原文
- **仅会话期处理**，会话结束后不保留任何数据
- **不分享**给其他用户或第三方
- 输出报告前提示用户："本审查仅在本次对话中进行，未存储您的合同"

#### 6.2 合规声明（每份审查报告必含）

```
本审查报告仅供参考，不构成法律意见或投资建议。

1. 本工具基于已公开披露的中国金融监管法规进行合同条款比对，
   不能替代持牌律师 / 投资顾问的专业意见。
2. 复杂场景（涉及关联方 / 跨境 / 衍生品 / 大额投资）建议咨询
   持牌律师事务所。
3. 本工具不对因依赖本审查报告而产生的任何损失承担责任。
4. 投资者应自行判断是否签署合同，并就投资决策征求专业人士意见。

签字前请最后阅读监管揭示书与产品说明书。
```

### 8. 多份合同对比模式

支持上传 2-3 份不同管理人 / 产品的合同做差异化对比：

```
对比维度 → 产品 A vs 产品 B vs 产品 C
管理费 → 1.5% vs 2.0% vs 1.2%
业绩报酬 → 20% (有高水位) vs 20% (无高水位) vs 15%
锁定期 → 12 月 vs 24 月 vs 6 月
赎回开放 → 月度 vs 季度 vs 月度
争议解决地 → 北仲 vs 偏远城市 vs 上仲

综合评分（投资者友好性）：A: 7.5/10 / B: 5.0/10 / C: 8.0/10
```

## 工作流 (High-Level Workflow)

### 阶段 1：合同接收与产品类型识别 (10-20 分钟)

1. 接收合同 PDF / 文本
2. 识别产品类型（私募 / 信托 / 银行理财 / 资管 / 专户）
3. 识别管理人 / 受托人 / 发行机构基础信息
4. 检查合同完整性（是否含正文 + 附件 + 风险揭示书）
5. 应用相应监管法规对照表

### 阶段 2：8 大维度逐项审查 (40-60 分钟)

按第 1 节 8 大维度，逐项扫描合同条款：
1. 费用条款（最常见陷阱区，重点扫描）
2. 赎回与清盘
3. 投资范围与关联交易
4. 信息披露义务
5. 合同变更与终止
6. 不可抗力与免责
7. 争议解决地点
8. 对投资者最不利条款

每个维度输出 🔴/🟡/✅ 标签 + 引用合同条款编号 + 法规依据。

### 阶段 3：白话翻译与协商建议 (10-20 分钟)

对所有 🔴 + 🟡 条款：
- 写白话翻译（200-300 字 / 条）
- 给协商建议（每条 3-5 个具体协商点）
- 引用监管处罚案例（如有）

### 阶段 4：投资者适当性评估 (5-10 分钟)

按第 9 节模型给出适当性评估结果。

### 阶段 5：审查报告生成与合规质检 (10-15 分钟)

- 按下方"产出物规范"输出 Markdown 报告
- 末尾附标准免责声明
- 提示用户"未存储您的合同"

详细分步指南详见 [references/workflow.md](references/workflow.md)。

## 关键术语规范化清单 ⭐ 强制术语规范

| 全称 | 简称 / 散户友好版 |
| :--- | :--- |
| 私募投资基金管理人 | 管理人 / "基金的经营公司" |
| 业绩报酬（Performance Fee） | "盈利提成" |
| 高水位线（High-Water Mark） | "盈利封锁线"（累计净值要破历史最高点才能再提成）|
| 回拨条款（Clawback Provision） | "回退条款"（之前提的业绩报酬，若整体亏损可追回）|
| 适当性义务 | "把适合的产品卖给合适的人" |
| 锁定期 | "不能赎回的期限" |
| 巨额赎回 | "单日 / 单月赎回额过大触发的特殊处理" |
| 资管新规 | 《关于规范金融机构资产管理业务的指导意见》（2018）|
| 净值化 | "产品净值实时反映投资结果"（替代过去的"预期收益型"产品）|
| 适当性匹配 | "投资者风险等级 ≤ 产品风险等级" |

**禁止用语清单**：

- ❌ "保本" / "稳赚" / "保收益" → ✅ 必须用"非保本浮动收益"
- ❌ "管理人一定不会..." → ✅ "本合同未明确约束 X，存在管理人滥用 Y 的风险"
- ❌ "建议买入 / 不买入" → ✅ "本合同含 X 个 🔴 不利条款，是否签署由投资者自行判断"
