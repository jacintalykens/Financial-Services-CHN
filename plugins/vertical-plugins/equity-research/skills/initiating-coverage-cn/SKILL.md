# A 股证券研究首次覆盖深度报告规范 (A-share Initiating Coverage)

创建符合中国证券业协会《发布证券研究报告执业规范》及国内顶级券商（中信证券、中金公司、海通证券、国泰君安、华泰证券、申万宏源）标准的 **A 股上市公司首次覆盖深度研究报告**，作为分析师对一支股票从 0 到 1 的全方位建仓研究输出。

**核心特征：**

- **报告篇幅**：30-50 页
- **字数规模**：10,000 - 20,000 字（深度中文金融术语）
- **核心表格**：12-20 张全面穿透财务明细表 + 历史沿革表
- **动态图表**：25-35 张（含行业供需推演、产业链图谱、PE/PB-Band、机构持仓变化）
- **响应时效**：3-6 周（全方位深度尽调）
- **目标受众**：尚未持仓的公募基金 / 私募 / 保险资管 / 券商资管，作为建仓决策依据
- **核心聚焦**：底层逻辑、商业模式、护城河、长期成长路径
- **字体规范**：宋体 / 微软雅黑（中文），Arial / Times New Roman（英文与数字）
- **字号规范**：与 earnings-analysis-cn 一致

## 触发场景 (When to Use)

**适用场景：**

- "帮我写一份华明装备（002270.SZ）的首次覆盖深度报告"
- "对宁德时代（300750.SZ）做建仓研究"
- "对北交所新上市的 [XX 公司] 做首次覆盖"

**严禁使用本技能的场景：**

- 用户请求**业绩点评** → 触发 [earnings-analysis-cn]
- 用户请求**行业综述** → 触发 [sector-overview-cn]
- 公司**已在覆盖池内** → 应触发 [model-update-cn] 或点评模板
- 纯港股 / 中概股 / 美股 → 触发海外模板
- 公司**上市不满 6 个月**（新股次新股）→ 建议等 1-2 个季报后再做首次覆盖，理由是缺乏可比基期

> ⚠️ 本节为骨架。主笔（尹紫佳）须按 [earnings-analysis-cn/SKILL.md](../earnings-analysis-cn/SKILL.md) 的深度逐条展开。

### 1. 公司历史沿革深度起底 ⭐ A 股本土化强制要求

A 股深度报告不能跳过历史，需完整起底：

- **上市路径**：IPO（主板 / 创业板 / 科创板 / 北交所）/ 借壳 / 分拆 + 上市日期 + 发行价 + 募资用途
- **实控人变更史**：每次股权转让、要约收购、协议转让的关键节点（巨潮"权益变动"专栏）
- **股权激励历史**：历次股权激励计划的考核目标、解锁条件、行权进度
- **重大资产重组**：并购、剥离、定增（区分配套融资 vs 战略增资）
- **历史诉讼 / 监管处罚**：证监会 / 交易所历史问询函与处罚记录
- TODO：实控人背景调查模板（教育背景、商业版图、关联公司）。

### 2. 商业模式深度拆解

- **收入结构**：按产品 / 按地区 / 按客户类型三维拆分（近 5 年趋势）
- **成本结构**：原材料 / 人工 / 折旧 / 研发占比
- **现金流模型**：To B / To C / 渠道分销 / 直销，账期与回款节奏
- **核心壁垒**：技术专利数 + 关键客户绑定 + 渠道资源 + 牌照壁垒

### 3. 行业格局研判（与 sector-overview-cn 互补）

- 引用 sector-overview-cn 的行业分类与产业链图谱
- 聚焦"公司在产业链中的定位"与"竞争位次变化"
- 必填：3-5 家直接可比的 A 股公司 + 1-2 家海外对标公司

### 4. A 股特色风险审查清单 ⭐ 强制章节

不同于英文版深度报告，A 股首次覆盖必须包含：

- **实控人背景与隐性关联交易**
- **股权质押结构**：控股股东 / 实控人 / 一致行动人质押率（巨潮"权益变动"）
- **限售解禁时间表**：未来 12 / 24 个月解禁数量与占流通股比例
- **机构持仓结构**：前十大流通股东 + 公募基金重仓 + 北上资金 + QFII / RQFII
- **审计意见类型**：标准无保留 / 保留 / 无法表示意见（核查近 3 年审计报告）
- **商誉占比与减值历史**
- **应收账款集中度**：前五大客户应收占比

### 5. 财务历史穿透（近 5 年）

- 三张表近 5 年完整数据 + 关键科目同比环比

- 复用 earnings-analysis-cn 的"利润双轨制"与"A 股地雷"清单

### 6. 三表预测（未来 3 年）

- 营收：按业务线 / 产品 / 地区分别预测
- 成本：原材料价格敏感性 + 产能利用率
- 费用：销售 / 管理 / 研发 / 财务费用率假设
- 现金流：营运资本变动 + 资本开支计划

### 7. 双估值法 ⭐ A 股核心方法论

**估值方法选择**（参考 earnings-analysis-cn 第 5.3 节，根据行业属性自适应）：

- **绝对估值**：DCF（默认必做）— 调用 [dcf-cn](../../financial-analysis/skills/dcf-cn/) skill
- **相对估值**：根据行业自适应（PE-Band / PB-Band / PS-Band / PB-ROE）— 调用 [comps-cn](../../financial-analysis/skills/comps-cn/) skill
- 必须二法交叉验证，给出**目标价区间**而非单一目标价

**评级体系**（A 股 5 档，参考 earnings-analysis-cn 第 5.1 节）：

| 评级 | 相对沪深 300（未来 6-12M） |
| :--- | :--- |
| 买入 | > +15% |
| 增持 | +5% ~ +15% |
| 中性 | -5% ~ +5% |
| 减持 | -15% ~ -5% |
| 卖出 | < -15% |

- 中小盘 / 北交所标的可参照中证 500 / 中证 1000 / 北证 50
- 首次覆盖建议起评不低于"增持"，"中性"起评需特殊说明理由

## 中国市场本土化深度内容 ⭐⭐⭐【强制填充段】

### A 股实控人深度调查清单（区别于海外标的的核心）

A 股首次覆盖必须对实控人 / 一致行动人做以下 7 维深度调查：

#### 7 维实控人画像

| 维度 | 调查内容 | 数据源 |
| :--- | :--- | :--- |
| **1. 教育背景** | 毕业院校 / 专业 / 学历 / 校友网络 | 公司年报"董监高简介" / 天眼查 / 企查查 |
| **2. 职业历史** | 工作单位 / 任职时长 / 创业经历 | 同上 + 巨潮"董监高任职履历" |
| **3. 商业版图** | 关联控股的其他公司 / 行业分布 | 启信宝 / 企查查"投资图谱" |
| **4. 持股结构** | 直接持股 / 间接持股 / 信托持股 / 一致行动人 | 公司年报"前十大股东" / "权益变动书" |
| **5. 历史套现记录** | 历次减持时间 / 价格 / 数量 / 减持后股价表现 | 巨潮"权益变动" / "股份减持" 专栏 |
| **6. 监管处罚记录** | 证监会 / 交易所历史处罚 / 警示函 | 证监会官网 + 中国裁判文书网 |
| **7. 关联方交易** | 与控股股东 / 实控人控股公司的交易历史 | 公司年报"关联交易"附注 |

#### A 股实控人 5 大典型风险信号

1. **频繁减持**：实控人 6 个月内累计减持 > 1% → 警告
2. **股权质押率高**：实控人质押率 > 70% → 平仓风险 / 控制权风险
3. **同业竞争**：实控人控股的其他公司与上市公司存在同业 → 利益输送嫌疑
4. **关联交易超 5%**：关联交易 / 营收 > 5% → 利润操纵嫌疑
5. **被立案调查**：证监会立案 / 警示函 → 直接风险
