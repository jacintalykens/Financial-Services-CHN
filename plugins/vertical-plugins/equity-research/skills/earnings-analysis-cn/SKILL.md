# A股证券研究业绩点评报告规范 (A-share Equity Research Earnings Update)

创建符合中国证券业协会《发布证券研究报告执业规范》及国内顶级券商（中信证券、中金公司、海通证券、国泰君安、华泰证券等）标准制度的 **A股上市公司业绩点评研报**，对覆盖池内股票在业绩预告 / 业绩快报 / 季报 / 半年报 / 年报发布后进行深度、即时的量化拆解。

**核心特征：**
- **报告篇幅**：8-12 页
- **字数规模**：3,000 - 5,000 字（深度专业中文金融术语）
- **核心表格**：1-3 张高度概括且具备财务勾稽关系的总结表（切忌冗长罗列）
- **动态图表**：8-12 张反映季度趋势、毛利率走势、费用率、估值通道的图表
- **响应时效**：24-48 小时内（业绩公告日 T 日 至 T+2 日）
- **目标受众**：已对该股票有基础了解的公募基金、私募基金、保险资管、券商资管等机构投资者
- **核心聚焦**：新变量、新趋势——重点剖析"实际业绩 vs 市场一致预期 vs 业绩预告中枢"的三方偏差、盈利预测修正、以及核心投资逻辑的动态演变
- **字体规范**：正文宋体 / 微软雅黑（中文），Arial / Times New Roman（英文与数字），除非用户另行指定
- **字号规范**：正文 10.5pt（五号）或 11pt；一级标题 14-16pt 加粗；二级标题 12pt 加粗；表格表头 10pt 加粗，表格正文 9pt；图注脚注 9pt（小五）

## 触发场景 (When to Use)

**适用场景：**
- "帮我写一份 [华明装备 002270.SZ] 2025 年三季报点评研报"
- "拆解 [宁德时代 300750.SZ] 最新的业绩快报 / 年报数据"
- "针对 [思源电气 002028.SZ] 刚刚发布的半年报撰写卖方点评"
- "分析 [比亚迪 002594.SZ] 季度业绩是否超出 Wind 一致预期"
- "针对 [贵州茅台 600519.SH] 业绩预告（预增 30%）撰写点评"
- "比较 [万华化学 600309.SH] 实际业绩与业绩快报的差异"

**严禁使用本技能的场景：**
- 用户请求 **"首次覆盖报告 / 深度研究报告"** → 触发【首次覆盖（Initiation）】技能。
- 用户请求 **"晨会纪要 / 闪电快评 / 一句话点评"** → 触发【闪电快评（Flash Note）】格式。
- 该上市公司从未建仓或不在覆盖池内 → 必须先撰写首次覆盖报告，理清历史底稿。
- **纯港股标的（如腾讯控股 0700.HK、美团 3690.HK、小米 1810.HK）** → 触发港股专用模板或美式 IFRS 模板，**不**使用本技能（披露口径、审计准则、报告频率均不同）。
- **中概股 / 美股标的（如阿里巴巴 BABA、拼多多 PDD、台积电 TSM）** → 触发美股 GAAP 版本（原英文 earnings-analysis 技能）。

**A+H 双重上市公司处理规范：**
- 默认按 **A 股口径** 撰写（A 股财报通常先于 H 股或同步披露）。
- 必须在报告中单独披露 H 股报表差异（如适用）：例如 IFRS 与中国会计准则下的少数股东权益、商誉摊销处理差异。
- 典型 A+H 标的举例：比亚迪（002594.SZ / 1211.HK）、宁德时代（300750.SZ / 3750.HK）、招商银行（600036.SH / 3968.HK）、中国平安（601318.SH / 2318.HK）。

**支持的板块（5 个）：**
- 沪市主板（600 / 601 / 603 / 605 开头）
- 深市主板（000 / 001 开头）
- 创业板（300 / 301 开头，注册制，2020 年改革）
- 科创板（688 开头，2019 年设立，注册制）
- 北交所（83 / 87 / 88 / 92 开头，2021 年 11 月开市，精选层升级而来）

不同板块的披露要求、投资者准入门槛、退市规则存在差异，撰写时需要识别板块属性并适配术语（例如科创板的研发投入资本化比例审查、北交所的中小市值估值参照系）。

## 核心执行要求

### 1. 极致的时效性与增量思维
- 报告必须在财报或业绩预告 / 快报公告后 24-48 小时内推向市场。
- 拒绝平铺直叙的"财报数字搬运"，全篇必须专注于 **"增量信息"（What's NEW）**。
- 严禁大篇幅罗列尽人皆知的公司历史背景和基础业务介绍（假设读者已读过首次覆盖底稿）。

### 2. 三方预期偏差分析（实际业绩 vs 市场一致预期 vs 业绩预告中枢）

#### 2.1 偏差判定输出强制要求
- 报告开篇前三行必须明确回答：公司业绩是 **"超预期"**、**"符合预期"**、还是 **"低于预期"**。
- 必须精确量化偏差幅度（例如："营业收入超出 Wind 一致预期 1.2 亿元或 3.5%，归母净利润落入此前业绩预告（预计 3.5-4.2 亿元）的中枢偏上限位置 4.05 亿元"）。
- 深度穿透 **"为什么"** 产生偏差：区分是行业 β 共性（如原材料降价、行业需求爆发、政策催化）还是公司自身的 α 特性（如特高压市占率提升、海外出海加速、新产品放量）。

#### 2.2 业绩预告类型识别（A 股法定 8 大分类）⭐ A 股特色硬性要求

在阶段 1 数据收集中，必须识别并标注业绩预告所属类型。这是 A 股证监会规定的法定分类，直接决定"超 / 低于预期"的判定基准：

| 业绩预告类型 | 定义 | 典型披露窗口 |
| :--- | :--- | :--- |
| **预增** | 净利润为正且同比增长 50% 以上 | 一季报预告 4/10 前；半年报预告 7/15 前 |
| **略增** | 净利润为正且同比增长 0-50% | 同上 |
| **续盈** | 净利润为正，去年同期也为正 | 同上 |
| **扭亏** | 净利润为正，去年同期为负 | 同上 |
| **首亏** | 净利润为负，去年同期为正 | 同上 |
| **续亏** | 净利润为负，去年同期也为负 | 同上 |
| **预减** | 净利润为正但同比下降 50% 以上 | 同上 |
| **略减** | 净利润为正且同比下降 0-50% | 同上 |

**强制操作规范：**
- 业绩快报披露的"具体数值"必须与正式财报数值进行勾稽校验，偏差超过 10% 必须解释原因。
- 业绩预告的"区间中枢"（如 3.5-4.2 亿元的中枢为 3.85 亿元）作为"管理层预期基准"，与 Wind 一致预期共同构成双重判定坐标。
- 三季报无强制预告义务（深市为强制、沪市为自愿），处理时需要区分。

### 3. A股本土化财务穿透与勾稽规范

#### 3.1 利润双轨制审查（A 股核心）
必须严格区分并同时列出以下三档利润口径：
- **净利润**（合并报表口径，包含少数股东损益）
- **归母净利润**（归属于上市公司股东的净利润，A 股核心利润指标）
- **扣非净利润**（扣除非经常性损益后的归属于上市公司股东的净利润，A 股最核心、最纯净的盈利指标）

**操作要求：**
- 评估 A 股企业真实核心盈利能力时，**必须以扣非净利润为基准**。
- 对非经常性损益（政府补贴、投资收益、资产处置损益、公允价值变动损益、营业外收支）进行逐项穿透说明，列示金额与税后影响。
- 关注 **"归母净利润 / 净利润"** 比例：差额即少数股东损益，对于控股集团（如比亚迪、海螺水泥、长江电力）影响显著，必须独立分析。

#### 3.2 股权激励费用单列分析 ⭐ 创业板 / 科创板必查

A 股自 2016 年后股权激励普及，单季度股权激励费用摊销常常吞噬 10-30% 的利润，必须在"扣非净利润穿透"环节单独列示：

- 列示 **股份支付费用** 当期金额及同比 / 环比变化（科目位于管理费用、研发费用、销售费用中，需穿透报表附注）。
- 计算 **"剔除股权激励费用后的扣非净利润"** 作为评估核心经营能力的辅助口径（尤其适用于科创板、创业板高研发投入公司）。
- 提示股权激励的解锁条件（业绩考核目标），这是管理层未来 1-3 年业绩指引的隐含信号。

#### 3.3 利润含金量（净现比）穿透
- 必须计算并分析 **"经营活动产生的现金流量净额 / 归母净利润"**。
- 若该比例偏离正常区间（低于 0.8 或环比大幅恶化），必须重点提示其营收的账面水分及回款风险。
- 关注 **"销售商品、提供劳务收到的现金 / 营业收入"** 作为回款质量的辅助指标。

#### 3.4 资产负债表蓄水池监控
- 深度核查 **【合同负债】**（新收入准则下取代原"预收账款"）的期末环比变动，将其作为评估下个季度业绩能见度的核心风向标。
- 监测 **【存货】** 期末余额结构（原材料、在产品、库存商品的占比变化），警惕存货跌价准备的计提风险。
- 关注 **【应收账款 + 应收票据 + 应收款项融资】** 合计变动，分析下游客户回款能力。
- 监测 **【长期借款 / 短期借款 / 一年内到期非流动负债】** 变动，警惕债务结构恶化与短债集中到期风险。

#### 3.5 A 股特色"地雷"监控清单 ⭐ 强制审查项

A 股投资者对以下"地雷"敏感度极高，每篇点评必须在风险提示章节明确审查：

- **【商誉减值】**：年报季（尤其 1-3 月）大额一次性减值是 A 股年报"业绩洗澡"的最常见手段，需通过附注"商誉"科目核查并对照前期评估报告。
- **【应收账款周转天数】**：警惕通过压货虚增收入或放宽信用政策做收入的行为，需观察是否显著高于行业均值。
- **【存货周转天数】**：警惕季节性因素之外的异常上升，可能预示需求疲软或库存积压。
- **【控股股东股权质押率】**：通过巨潮"权益变动"专栏核查最新质押比例。质押率超过 70% 触发警报，超过 90% 警示平仓风险。
- **【董监高减持公告】**：通过"股份减持"专栏核查报告期前后 30 天内的减持记录与减持比例。高频减持是利空先行指标。
- **【非经常性损益占比】**：若非经常性损益 / 归母净利润超过 30%，必须明确提示"业绩质量较低、不可持续"。

#### 3.6 四费率（销售 / 管理 / 研发 / 财务费用率）拆解
- 计算四费率（费用 / 营业收入）的同比与环比变动。
- 定位特殊变动来源：股权激励费用大摊销、研发投入加大、债务结构变化（财务费用）、市场拓展期（销售费用上升）。
- 科创板公司需要特别审查 **【研发投入资本化比例】** 与 **【研发投入占营业收入比例】**（科创板硬指标，需 ≥5% 或最近三年累计研发投入 ≥6,000 万）。

#### 4.3 必查并引用的数据源清单（6 项硬性要求）

每篇 A 股业绩点评研报必须完整引用以下材料：

- ✅ **上市公司官方发布的财报原文 / 业绩快报 / 业绩预告公告**（包含披露日期及巨潮链接 / 沪深交易所披露链接）
- ✅ **管理层讨论与分析（MD&A）或董事会经营评述章节**（位于定期报告"经营情况讨论与分析"部分）
- ✅ **交易所投资者关系活动记录表**（深交所互动易 / 上交所 e 互动 / 北交所相应专栏，含调研日期与机构名单）
- ✅ **本次财报发布前的"业绩预告"或"业绩快报"**（用于对比是否符合预期，A 股法定信息）
- ✅ **市场第三方主流数据终端的"一致预期"数据**：Wind（核心，券商首选）/ 同花顺 iFinD / 东方财富 Choice / 雪球 / FactSet。**必须明确数据提取的截止日期（应为公告日前 1 个交易日收盘后）**。
- ✅ **团队在上一个季度报告中给出的旧版盈利预测与投资评级**（用于对比修正幅度）

#### 4.4 机构持仓与北上资金数据源（A 股特色）

定期报告披露的股东信息必须完整引用：
- **【前十大股东】** 与 **【前十大流通股东】**（每份定期报告附录强制披露）
- 国家队、社保基金、险资、QFII / RQFII 持仓变动（通过名称识别：例如"中央汇金"、"全国社保基金一一X组合"、"中国人寿保险"、"OPPENHEIMER"）
- **【北上资金 / 陆股通持仓】**（每日更新，数据源：港交所披露易 https://sc.hkexnews.hk/TuniS/www.hkexnews.hk/sdw/search/mutualmarket_c.aspx，或 Choice / Wind 终端）
- **【公募基金重仓股】**（季报披露，可通过基金定期报告或天天基金网 / Wind"基金重仓股"工具核查）
- **【机构调研频次】**（互动易 / Choice"调研次数"排名，反映机构关注度变化）

### 5. 盈利预测、评级体系与估值矩阵动态修正

#### 5.1 评级体系（A 股标准 5 档）⭐ 本土化强制要求

A 股标准卖方评级体系（与美股的 Buy/Hold/Sell 不同）：

| 评级 | 定义（未来 6-12 个月相对收益） | 操作含义 |
| :--- | :--- | :--- |
| **买入** | 相对沪深 300 指数超额收益 > 15% | 强烈推荐配置 |
| **增持** | 相对沪深 300 指数超额收益 5%-15% | 建议超配 |
| **中性** | 相对沪深 300 指数收益 ±5% | 维持现有配置 |
| **减持** | 相对沪深 300 指数超额收益 -15% 至 -5% | 建议低配 |
| **卖出** | 相对沪深 300 指数超额收益 < -15% | 强烈建议减仓 |

**强制要求：**
- 评级时间维度统一为 **"未来 6-12 个月"**。
- 基准指数默认为 **沪深 300**；中小盘 / 北交所标的可参照中证 500 / 中证 1000 / 北证 50；行业基准可叠加申万一级行业指数。
- 给出目标价的同时，必须明示 **"相对当前股价的预期收益率"** 与 **"相对沪深 300 的超额收益预期"**。

#### 5.2 盈利预测三表联动修正
- 根据最新财报暴露的产能、订单、毛利率、费用率变动，重新修正未来 3 年的模型假设。
- 清晰列示 **旧版预测 vs 新版预测** 表格（对比营收、毛利率、归母净利润、扣非净利润、EPS、ROE）。
- 修正幅度超过 ±5% 需要解释具体驱动因素。

#### 5.3 估值通道自适应选择（A 股核心方法论）⭐

根据公司所处行业属性，自适应选择最合适的估值方法：

| 行业属性 | 主估值方法 | 辅助估值方法 |
| :--- | :--- | :--- |
| **高增长成长股**（半导体、新能源、医药创新） | **PE-Band**（动态 PE） | PEG、EV/EBITDA |
| **金融股**（银行、券商、保险） | **PB-Band**（市净率通道） | PE、股息率、PB-ROE |
| **地产 / 建筑 / 建材**（周期股） | **PB-Band** | NAV 重估、PE 历史分位 |
| **消费白马 / 医药龙头**（高 ROE 稳定型） | **PB-ROE 框架**（巴菲特启发） | DCF、PE-Band |
| **亏损成长股**（创业板 / 科创板未盈利） | **PS-Band**（市销率） | EV/Sales、EV/Daily Active User |
| **大宗周期股**（钢铁、煤炭、化工） | **历史 PB 分位 + 行业景气位置** | PE 顺周期低估、EV/Capacity |

**默认操作：**
- 默认输出 **PE-Band** 与 **PB-Band** 双估值通道图（覆盖近 5 年历史区间，标注当前位置分位数）。
- PB-ROE 框架（横轴 ROE、纵轴 PB，行业散点图）适用于消费、医药、家电、白酒等高 ROE 稳定行业。
- 估值结论必须给出 **【相对估值矩阵法】**：拉出至少 3 家核心可比公司的估值对标表，给出维持或调整评级 / 目标价的定量依据。

#### 5.4 敏感性分析
- 必须提供二维敏感性分析表：**[关键驱动变量 1] × [关键驱动变量 2]** → 目标价或 EPS 敏感度（例如：原材料价格 × 销量增速、特高压招标量 × 海外出货占比）。
- 输出"乐观 / 中性 / 悲观"三档情景对应的目标价区间。

**为什么必须用模板而非自由生成？**

| 自由生成（add_paragraph 顺序堆） | 调用 build_cover_page() |
| :--- | :--- |
| ❌ 必然单栏，AI 无法在 docx 中产生真正的双栏布局 | ✅ 用 1×2 无边框表格做容器，左右栏严格并排 |
| ❌ 颜色 / 字体 / 字号容易漂移 | ✅ 锁定 6 色 + 14 行字号规范 |
| ❌ 嵌套结构（财务表、评级框）容易缺失 | ✅ 强制嵌套，自检会发现缺失 |
| ❌ 中文字体 eastAsia 字段易漏 | ✅ `_set_eastasia_font()` 自动处理 |
| ❌ OxmlElement（背景色、页码字段）易漏 | ✅ 已封装，调用一次全配齐 |

## 研报标准撰写工作流 (High-Level Workflow)

全流程分为 5 个标准研究阶段：

### 阶段 1：数据清洗与雷达检索 (30-60 分钟)

**🚨🚨🚨 核心防御机制：杜绝使用 AI 训练集中的陈旧过期数据 🚨🚨🚨**

**在开始码字之前，必须严格执行以下 A 股行情核查四步法：**

1. **核实今日交易日**：确认当前精确的年、月、日，明确当前处于哪一个财报披露季（一季报 4 月底前、半年报 8 月底前、三季报 10 月底前、年报 4 月底前）。
2. **全网雷达检索**：调用搜索工具执行：`[股票简称/代码] 最新财报 公告 巨潮` 以及 `[股票简称/代码] 业绩点评 研报 2025` / `[股票简称/代码] 业绩预告`。
3. **财报时效性验证**：必须确认你检索到的财报发布日期距离今天在 **3 个月以内**。如果是过往的旧财报，必须提示用户并重新检索最新季度的公告。
4. **纪要对齐验证**：确认搜集到的券商调研纪要或互动易记录表的日期，是在财报发布日当天或紧随其后的 3 个交易日内。

**严禁犯的低级错误**：直接依赖底层的静态大模型记忆去虚构、拼凑过期的公司财报数据。

**详细的检索操作指南详见 [references/workflow.md](references/workflow.md)。**

### 阶段 2：三张表穿透与量化分析 (2-3 小时)
- 执行核心业务板块的 **"量价拆解"**（例如华明装备：国内设备 / 出海设备 / 特高压产品 / 检修服务的收入与毛利率拆分）。
- 计算四费（销售、管理、研发、财务费用率）的同比环比变动，定位特殊变动（股权激励大摊销、研发资本化变化等）。
- 测算净现比、应收账款周转天数、存货周转率、合同负债环比，给财务健康度打分。
- 核查控股股东最新质押比例与董监高减持记录。
- 细化未来 3 年盈利预测模型的底层驱动参数。

### 阶段 3：可视化财务图表绘制 (1-2 小时)

在 Word 报告中对应生成 8-12 张高清晰度、券商风格的专业财务图表，推荐使用 Matplotlib / Seaborn 渲染后导出（中文字体配置详见 workflow.md）：

- **图 1**：近 8 个季度单季营业收入及同比增速趋势图（柱状图 + 折线叠加）
- **图 2**：近 8 个季度单季归母净利润与扣非净利润对比柱状图
- **图 3**：近 5 年及预测期毛利率与净利率走势曲线
- **图 4**：主营业务板块收入结构拆分（饼图 / 堆叠柱状图）
- **图 5**：四费率（销售 / 管理 / 研发 / 财务）季度走势叠加图
- **图 6**：应收账款与存货周转天数历史对比图
- **图 7**：合同负债（预收款）期末余额季度环比变动雷达图
- **图 8**：实际业绩 vs Wind 一致预期 vs 业绩预告中枢的三方偏差对比柱状图
- **图 9**：未来 3 年归母净利润预测调整对比（新旧预测叠加柱状图）
- **图 10**：可比公司 2025E / 2026E PE / PB / PS 估值多维度对比图（取决于行业属性）
- **图 11**：公司历史 PE-Band 或 PB-Band 估值通道图（叠加 ±1σ 标准差区间）
- **图 12**（可选）：北上资金陆股通持股比例变动趋势图 / 公募基金重仓持仓变动图

### 阶段 4：专业 DOCX 研报文本撰写 (2-3 小时)

严格基于标准页面排版和段落级模板，输出深度中文证券研究点评报告。

**详细的逐页模板与排版规范详见 [references/report-structure.md](references/report-structure.md)。**

**报告标准分页结构（强制 14 页式，参考国元证券 / 中信建投样式）：**

- **第 1 页**：封面与核心总控台。
  - 左上：行业分类标识（如"公司研究 | 工业 | 资本货物"）+ "证券研究报告 [公司名]([代码]) [报告期]点评"
  - 左中：**双标题**（主标题观点一行 + 副标题"——公司名（代码）[报告期]点评"一行）
  - 左下：**报告要点**（4-5 段 paragraph 风格，**不**用 bullet 形式），每段一个核心子论点 + 量化支撑
  - 左下底部：**首页"财务数据和估值"摘要表**（7×5 标准格式，见 §6.2）
  - 右上至右下：**首页 panel**（评级框 + 当前价 + 基本数据 + 过去一年股价走势图 + 相关研究报告 + 报告作者，**5 段式强制**，见 §6.1）
- **第 2 页**：一、财报整体业绩拆解 ①
  - 1.1 营收增速结构性分析（同比 / 环比 / 长序列对比）
  - 1.2 归母与扣非利润增速对比，剔除股权激励后扣非
  - 含 1-2 张图（季度营收柱状图 / 归母 vs 扣非对比图）
- **第 3 页**：一、财报整体业绩拆解 ②
  - 1.3 综合毛利率与净利率走势（含历史 + 预测期）
  - 1.4 季度利润勾稽汇总表（关键科目环比 / 同比变动）
  - 1.5 实际业绩 vs 一致预期 vs 业绩预告中枢三方偏差柱状图
- **第 4 页**：二、业务板块量价拆解 ①
  - 2.1 分业务收入与毛利率（**用 §6.3 标准表格，不用段落**）
  - 含分业务营收占比堆叠柱状图
- **第 5 页**：二、业务板块量价拆解 ②
  - 2.2 海外业务专题（直接出口 + 间接出口拆解）
  - 2.3 国内分地区 / 分客户分析（如适用）
- **第 6 页**：三、财务质量穿透与 A 股地雷监控
  - 3.1 净现比与四费率
  - 3.2 资产负债表蓄水池（合同负债 / 应收 / 存货）
  - 3.3 A 股地雷清单（商誉 / 质押 / 减持 / 回购 / 非经常 / 分红）—— 用 "✓ / ⚠ / ✗" 标识，每条 ≤2 行
- **第 7 页**：四、行业格局研判 ①
  - 4.1 国内：电网投资 / 政策催化 / 行业 β
- **第 8 页**：四、行业格局研判 ②
  - 4.2 海外：全球需求 / 地缘 / 公司海外布局
  - 4.3 投资逻辑 3-4 条动态再评估（每条标注"加强 / 维持 / 减弱"）
- **第 9 页**：五、盈利预测调整与估值矩阵 ①
  - 5.1 盈利预测核心假设修正（按业务线展开，每条假设含量化）
  - 5.2 盈利预测调整对比表（前次 vs 本次，列示营收 / 毛利率 / 归母净利润 / EPS）
- **第 10 页**：五、盈利预测调整与估值矩阵 ②
  - 5.3 可比公司估值对标表（**用 §6.4 标准 9 列格式**）
  - 5.4 估值通道图（PE-Band / PB-Band 二选一或并列）
  - 5.5 二维敏感性分析表
  - 5.6 **评级决策 + 目标价推导**（这里才是评级和目标价的"正式宣布点"，不在首页核心要点中提前透露细节）
- **第 11 页**：六、风险提示
  - 宏观层 2 项 / 行业层 2 项 / 公司层 2-3 项 / 政策层 1-2 项，每项必须**量化敏感度**
- **第 12 页**：七、参考资料及信息来源
  - 4 大类组织：公司公告 / 投资者关系 / 第三方数据 / 行业与监管
- **第 13 页**：附录·财务预测表（**§6.6 强制 4 块结构**）—— 资产负债表 + 利润表 + 现金流量表 + 主要财务比率
- **第 14 页**：八、分析师承诺与免责声明 + 分析师介绍 + 研究服务联系人（**§6.7 强制**）
  - 分析师承诺
  - 免责声明
  - 评级体系说明
  - 分析师介绍
  - 报告贡献人
  - 研究服务联系人（北京 / 上海 / 深圳 / 公募 / 保险）

**评级与目标价的出现位置规则（重要！）**：
- 首页 panel 评级框 → **只标"买入 / 维持"**（一字结论）
- 首页报告要点 → **可提目标价数字与上行空间**，但**不展开 PE 倍数推导**
- 第 10 页 §5.6 → 是评级与目标价的**正式宣布点**，含完整 PE 倍数选取理由、可比公司折溢价说明、未来 6-12 个月相对沪深 300 收益预期
- 第 14 页 → 标准评级体系说明（5 档定义表）

### 阶段 5：合规与勾稽质检 (30 分钟)

交付前的全方位自我审查，确保数据零低级错误。详细质检清单与排雷指南详见 [references/best-practices.md](references/best-practices.md)。

| 存货周转天数 | DIO（存货周转天数） |
| 合同负债 | 合同负债（原"预收账款"，新收入准则 2018 年起） |

**禁止用语清单：**
- ❌ "强劲增长" / "大幅提升" → ✅ "营收同比 +35.2%" / "毛利率提升 3.8pct"
- ❌ "未来可期" / "前景广阔" → ✅ 必须给出具体测算的预期收益率
- ❌ "推荐" / "看好" / "重点关注" → ✅ 必须使用标准评级（买入 / 增持 / 中性 / 减持 / 卖出）

**国内卖方研报特色笔法清单（推荐高频使用）：**

国内研报有一套与海外研报截然不同的"笔法体系"。AI 输出若不掌握，会显得"洋气有余、专业不足"。**每段正文应至少包含 1 个以下笔法**：

| 类别 | 笔法 | 使用示例 |
| :--- | :--- | :--- |
| **观点引领** | 我们认为 / 我们判断 / 我们预计 | "我们判断公司海外业务在 2026-2027 年保持 35-45% 的高速增长" |
| **观点引领** | 标志 / 拐点已现 / 已进入 X 阶段 | "公司在 500kV 以上市场已从突破走向批量化的拐点" |
| **观点引领** | 充分体现 / 验证 / 兑现 | "海外业务超预期增长充分验证了公司全球化战略" |
| **趋势性表述** | 中枢上行 / 中枢下行 | "毛利率中枢上行至 55% 以上" |
| **趋势性表述** | 边际改善 / 边际恶化 | "费用率边际改善 0.8pct" |
| **趋势性表述** | 动能切换 / 业务切换 | "业务从国内驱动切换至海内外双轮驱动" |
| **趋势性表述** | 持续抬升 / 稳步抬升 | "北上资金持股比例从 10.8% 持续抬升至 14.72%" |
| **量化表述** | XX 增速达到 / 升至 / 抬升至 X% | "海外营收占比抬升至 10.07%" |
| **量化表述** | 同比 +X% / 环比 +X% / YoY / QoQ | "归母净利润同比 +15.54%" |
| **量化表述** | X pct（百分点）/ X bps | "毛利率提升 1.34pct" |
| **量化表述** | 处于近 X 年中枢偏上 / 偏下水平 | "估值处于近 5 年中枢偏下水平" |
| **结构性表述** | 核心驱动 / 三大驱动力 / 双轮驱动 | "三大驱动力共同贡献" |
| **结构性表述** | 加强 / 维持 / 减弱（逻辑标签） | "▶ 逻辑支柱 1：海外出口高速增长 → 【加强】" |
| **结构性表述** | 业绩弹性 / 估值弹性 | "公司未来利润弹性较大" |
| **行业表述** | 国产替代 / 自主可控 | "公司打破海外品牌（MR、ABB）的绝对垄断" |
| **行业表述** | 龙一 / 龙二 / 隐形冠军 | "国内分接开关龙一" |
| **行业表述** | 卡脖子 / 关键零部件 | "分接开关是变压器的关键卡脖子部件" |
| **风险表述** | 不及预期 / 超预期 | "海外业务开拓不及预期风险" |
| **风险表述** | 节奏 / 时间窗口 | "招标节奏对业绩的影响" |
| **估值表述** | 估值切换 / 估值重估 | "公司有望从'国内龙头'估值切换至'全球龙头'" |
| **估值表述** | 给予 X% 估值溢价 / 折价 | "给予 20% 估值溢价" |
| **估值表述** | 隐含 / 对应目标价 | "对应目标价 21.50 元" |

**笔法分布建议**：
- 报告要点（第 1 页）：每段 ≥2 个笔法
- 业绩拆解 / 业务板块（正文）：每段 ≥1 个笔法
- 投资逻辑章节：每条逻辑标注"加强 / 维持 / 减弱"

## 产出物最终交付技术规范 (Output Specification)

**核心交付成果**：无瑕疵、券商标准格式的 Word 文件（DOCX）

**规范文件命名**：`[公司简称]_[股票代码]_[报告期]_业绩点评研报_A股证券研究.docx`

**范例展示**：
- `宁德时代_300750.SZ_2025Q3_业绩点评研报_A股证券研究.docx`
- `贵州茅台_600519.SH_2025H1_业绩点评研报_A股证券研究.docx`
- `华明装备_002270.SZ_2024A_业绩点评研报_A股证券研究.docx`（年报点评）
- `比亚迪_002594.SZ_2025Q3业绩预告_业绩点评研报_A股证券研究.docx`（业绩预告点评）

**报告期标识规范：**
- `Q1` / `Q2` / `Q3` / `Q4` = 单季度
- `H1` / `H2` = 半年度

- `业绩预告` / `业绩快报` = 单独标识

**必备要素结构：**
- 标准前页：包含最新基本市场数据（截止最新交易日收盘价、总市值、自由流通市值、总股本、A/H 股溢价率、近 30 日日均换手率等）。
- 8-12 张完全自主生成、拒绝断层的财务分析图表。
- 1-3 张标准化多周期预测缩略表（严禁直接贴巨大的原始 Excel 全表）。
- 包含完整官方超链接、符合合规执业规范的参考引文与来源声明。
- 标准免责声明章节（券商发布证券研究报告执业规范强制要求）。

## 业绩点评报告与深度首次覆盖报告的战略差异

| 评估维度 | A 股业绩点评报告（本技能） | 首次覆盖 / 深度研究报告 |
| :--- | :--- | :--- |
| **报告篇幅** | 8 - 12 页 | 30 - 50 页 |
| **字数规模** | 3,000 - 5,000 字 | 10,000 - 20,000 字 |
| **数据表格** | 1 - 3 张核心勾稽总结表 | 12 - 20 张全面穿透财务明细表 |
| **动态图表** | 8 - 12 张，聚焦核心财务变量 | 25 - 35 张，包含行业供需、产业链图谱 |
| **时效响应** | 1 - 2 天（快节奏、闪电发布） | 3 - 6 周（全方位深度尽调） |
| **核心视角** | 捕捉 **"新变量"** 与业绩超预期偏差 | 理清 **"底层逻辑"**、商业模式与核心壁垒 |
| **公司历史背景** | 寥寥数笔，假设读者完全知晓 | 6 - 10 页，对历史沿革、高管履历彻底起底 |
| **Excel 底层模型** | 预测模块快速修正调整（可选） | 必须从零搭建全手工内生勾稽模型（硬性强制） |
| **行业研究深度** | 仅引用最新景气数据 | 完整产业链 + 供需推演 + 竞争格局 |
