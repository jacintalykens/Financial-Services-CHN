# A 股业绩点评研报详细工作流

本文档为 A 股业绩点评研报的 5 阶段工作流提供逐步执行指南，重点覆盖巨潮资讯网检索、Wind 一致预期获取、业绩预告类型识别、机构持仓数据源、以及 Matplotlib 中文图表渲染等 A 股特有环节。

## ⚠️⚠️⚠️ 核心警告：必须使用最新业绩数据 ⚠️⚠️⚠️

**先停下来阅读这段：**

AI 训练数据是过时的。**必须主动检索并获取最新的 A 股财报材料**。使用过期财报数据是 A 股业绩点评中最常见、最致命的错误。

**开始撰写之前，请严格执行：**

1. **核实今日日期** —— 明确写下当前日期与所处的财报披露窗口
2. **搜索最新业绩** —— 用 Web 搜索 / 巨潮 / Choice 找最近一次披露
3. **验证披露日期** —— 确认距离今天 ≤ 3 个月（一季报 / 半年报 / 三季报 / 年报披露窗口）
4. **若超过 3 个月** —— 错误的季度，重新搜索

## 阶段 1：业绩材料检索与收集（30-60 分钟）

### Step 1：识别最新业绩披露期

**🚨 核心要求**：永远主动搜索最新业绩——不要依赖知识截止日期。

#### Step 1a：搜索最新业绩公告

**强制步骤 1：写下今日日期**
- 明确写出："今天是 2026 年 5 月 24 日"
- 用此日期验证检索到的业绩在 3 个月以内

**强制步骤 2：搜索"最新业绩"**

A 股专用搜索查询：
- `[公司简称/股票代码] 最新财报 巨潮`
- `[公司简称/股票代码] 业绩预告 2025`
- `[股票代码] 季报 半年报 年报 公告`
- `[公司简称] 业绩快报`

或直接访问以下信息源：

| 数据源 | 网址 | 用途 |
| :--- | :--- | :--- |
| **巨潮资讯网** | http://www.cninfo.com.cn | 沪深 + 北交所法定信息披露官方平台 |
| **上交所信息披露** | http://www.sse.com.cn/disclosure/listedinfo/announcement/ | 沪市公司公告 |
| **深交所信息披露** | http://www.szse.cn/disclosure/listed/notice/index.html | 深市公司公告 |
| **北交所** | https://www.bse.cn/disclosure_list_more.html | 北交所公司公告 |
| **东方财富 Choice** | 终端登录 | 一致预期、机构持仓、行情数据 |
| **同花顺 iFinD** | 终端登录 | 一致预期、研报库 |
| **Wind 金融终端** | 终端登录 | 一致预期（机构金标准）、研报库、行情 |
| **雪球** | https://xueqiu.com | 散户 + 卖方研报汇总参考 |
| **新浪财经 / 东方财富网** | sina.com / eastmoney.com | 公众版财报数据 |

**强制步骤 3：验证披露日期**
- 看公告页面或 PDF 内页的"公告日期"
- 计算距今天的间隔（应 ≤ 90 天）
- 是 → 进入下一步；否 → 🚨 错误季度，重新搜索

**❌ 常见错误：**
- ❌ 直接用训练数据里的"已知"业绩数字
- ❌ 假定"现在是 2026 年 5 月，那肯定是 2025 年报"
- ❌ 找到一篇旧报告就直接用
- ❌ 没对照今天的日期做时差计算

**✅ 正确方法：**
- ✅ 先核今天日期
- ✅ 主动搜"最新""最近""刚发布"
- ✅ 读公告原文 PDF 上的实际日期
- ✅ 确认在 3 个月内
- ✅ 不确定就换关键词再搜

#### Step 1b：识别报告类型（A 股特色法定 8 大业绩预告分类）

如果检索到的是 **业绩预告** 而非完整财报，必须识别其法定分类：

| 类型 | 触发条件 | 操作要点 |
| :--- | :--- | :--- |
| **预增** | 净利润为正且同比 +50% 以上 | 重点分析增长持续性、是否含一次性损益 |
| **略增** | 净利润为正且同比 0-50% | 关注边际改善 / 恶化趋势 |
| **续盈** | 净利润为正、去年同期也为正 | 偏中性，关注扣非利润质量 |
| **扭亏** | 净利润为正、去年同期为负 | 关注扭亏来源（主业 vs 非经常） |
| **首亏** | 净利润为负、去年同期为正 | 重大利空，深挖原因 |
| **续亏** | 净利润为负、去年同期也为负 | 退市风险（ST/*ST）警示 |
| **预减** | 净利润为正但同比 -50% 以上 | 重大利空，业绩拐点分析 |
| **略减** | 净利润为正且同比 -0-50% | 关注是否短期扰动 |

**业绩预告 vs 业绩快报 vs 正式财报：**
- **业绩预告**：仅披露区间数（如"预计 3.5-4.2 亿元"），无完整三表
- **业绩快报**：披露具体数值，简化版三表（自愿披露，年报披露率较高）
- **正式财报**：完整三表 + 附注 + MD&A + 审计意见（年报）

### Step 2：收集业绩材料

确认了最新报告期后，逐项收集：

#### 主要材料（强制必备）

**1. 财报原文 PDF（巨潮官方版本）**
- 路径：巨潮资讯网 → 搜公司名 / 代码 → 信息披露 → 定期报告
- 文件命名规范：`[公司简称]：YYYY年[报告期]报告全文.pdf`
- 必读章节：
  - 重要提示（业绩亮点 / 风险提示）
  - 第二节"公司基本情况"中的主要会计数据和财务指标
  - 第三节"管理层讨论与分析"（MD&A）
  - 第十节"财务报告"附注（重点核查商誉、合同负债、应收账款、存货）

**2. 业绩预告 / 业绩快报公告**
- 若有，必须对比预告区间中枢与实际值
- 巨潮路径：信息披露 → 临时公告 → 关键字"业绩预告"或"业绩快报"

**3. 交易所投资者关系活动记录表**

| 板块 | 平台 | URL |
| :--- | :--- | :--- |
| 深市（含创业板） | 深交所互动易 | http://irm.cninfo.com.cn/ |
| 沪市（含科创板） | 上证 e 互动 | http://sns.sseinfo.com/ |
| 北交所 | 北交所投资者互动平台 | https://www.bse.cn/disclosure_list_more.html |

- 查询：报告期前后 30 个交易日的调研记录
- 重点：参与调研的机构名单（公募 / 私募 / 险资 / QFII / 卖方券商）
- 频次越高 → 机构关注度越高

**4. Wind / Choice / iFinD 一致预期数据**
- 必须截止于业绩公告日的前 1 个交易日收盘
- Wind 路径：[股票代码] → DCM 模块 → 盈利预测 → 一致预期 → 设置截止日期
- Choice 路径：F9 → 盈利预测 → 一致预期汇总
- 若无机构终端，可用东方财富网 / 雪球 / 新浪财经的卖方一致预期汇总作为替代（精度略低）

**5. 上次研报底稿（团队自留）**
- 上一份点评 / 首次覆盖给出的 EPS 预测、目标价、评级
- 用于对比"旧版 vs 新版"修正

#### 补充材料（可选但强烈推荐）

- **业绩说明会纪要 / 路演纪要**（部分公司主动召开，路径同投资者关系活动记录）
- **公司投资者关系活动 PPT**（部分公司在巨潮上传管理层 PPT）
- **审计报告**（年报必备，关注关键审计事项与意见类型：标准无保留 / 带强调事项段 / 保留意见 / 否定意见 / 无法表示意见）

### Step 3：A 股机构持仓数据收集

| 数据类型 | 数据源 | 提取要点 |
| :--- | :--- | :--- |
| **前十大股东** | 定期报告附录 | 持股变动、是否新进 / 减持 |
| **前十大流通股东** | 定期报告附录 | 真正可交易筹码集中度 |
| **北上资金 / 陆股通持仓** | 港交所披露易 https://sc.hkexnews.hk/TuniS/www.hkexnews.hk/sdw/search/mutualmarket_c.aspx | 每日持股 / 占总股本比例变动 |
| **公募基金重仓** | Wind / Choice / 天天基金网 | 当季新进 / 增持 / 减持的基金数量 |
| **国家队（中央汇金、证金）** | 前十大股东识别 | 是否进出 |
| **社保基金组合** | 前十大股东识别（如"全国社保基金 X 组合"） | 持仓变动 |
| **QFII / RQFII** | 前十大股东识别（如"OPPENHEIMER FUND"、"摩根大通"） | 持仓变动 |
| **机构调研频次** | Choice → 调研次数排名 / 互动易统计 | 报告期前后 30 日内的调研家数 |

### Step 4：A 股地雷监控数据收集

强制核查以下高敏数据点：

- **【控股股东股权质押】**：路径——巨潮 → 临时公告 → 关键字"质押"。提取最新质押比例（占持股的比例）与质押率（占总股本的比例）。
- **【董监高股份变动】**：路径——巨潮 → 临时公告 → 关键字"股份减持"或"增持"。统计报告期前后 30 个交易日内的增 / 减持记录。
- **【商誉账面价值】**：从最新资产负债表附注提取，对比上期是否大额减值。
- **【非经常性损益明细】**：从财报附注"非经常性损益明细表"提取分项。
- **【关联方交易】**：从财报附注提取，警惕大额关联方资金往来。

### Step 4.5：首页 Panel 与摘要表数据采集（强制专项步骤）⭐

⚠️ 这是国内研报区别于英文 sell-side note 的关键。**第 1 页右栏 Panel 与首页摘要表所需数据必须在阶段 1 集中采集**。

#### 4.5.1 Panel 评级与价格数据
- 当前股价：取**最近一个交易日收盘价**（Wind / Choice 实时行情）
- 取数日期：明确标注（如"2026-05-22 收盘"）
- 评级方向（维持 / 上调 / 下调 / 首次）：与团队上一次研报对比确定

#### 4.5.2 Panel 基本数据 5 字段（必填）
- 52 周最高价 / 最低价（元）：Wind 字段 `WSD.High_52w` / `WSD.Low_52w`
- A 股流通股本（百万股）：Wind 字段 `WSD.Float_a_shr`
- A 股总股本（百万股）：Wind 字段 `WSD.Total_shares`
- 流通市值（百万元）：当前股价 × A 股流通股本
- 总市值（百万元）：当前股价 × 总股本

**取数代码示例**（Wind API）：
```python
from WindPy import w
w.start()
# 取数日期：报告发布日前一交易日
data = w.wsd("002270.SZ", "high_52w,low_52w,float_a_shr,total_shares,close", 
             "2026-05-22", "2026-05-22", "Days=Trading")
```

#### 4.5.4 Panel 相关研究报告
- 取数源：本团队本年度发布的 2-3 篇相关报告（按时间倒序）
- 字段：报告标题简短版 + 发布日期
- 示例：

  - "华明装备 2024 年三季报点评（2024-10-28）"
  - "输变电设备行业深度报告（2024-12-15）"

#### 4.5.5 首页 "财务数据和估值" 摘要表 7 行数据

```
营业收入（百万元）       — 利润表"营业收入"行（历史 + 预测）
收入同比（%）            — (当期营收 / 上期营收 - 1) × 100%
归母净利润（百万元）     — 利润表"归属于母公司股东的净利润"
归母净利润同比（%）      — (当期归母 / 上期归母 - 1) × 100%
ROE（%）                 — 加权 ROE（财报附注或 Wind 计算）
每股收益（元）           — 基本 EPS（财报披露或 归母 / 总股本）
市盈率（P/E）            — 当前股价 / EPS
```

**5 列规则**：
- 年报点评：2 历史年（如 2024A / 2025A）+ 3 预测年（2026E / 2027E / 2028E）
- 一季报点评：1 历史年（2025A）+ 4 预测年（2026E-2029E）

- 联系电话（区号 010 / 021 / 0755）
- 邮箱（机构邮箱后缀）
- 联系人姓名与电话

## 阶段 2：财务穿透与量化分析（2-3 小时）

### Step 6：三方预期偏差分析

针对每个核心指标，进行三方对比分析：

```
■ 营业收入：[超 / 符合 / 低于] Wind 一致预期 X.X%

实际 X.XX 亿元 vs Wind 一致预期 Y.YY 亿元，偏差 +/-X.X%。
[与业绩预告对比]：预告区间 [Z.Z-Z.Z 亿元]，实际值落入区间[下限 / 中枢 / 上限 / 超出区间]。

驱动因素分析：
+ 国内 [板块/产品] 销售收入 X.XX 亿元（YoY +X%），主因 [具体原因]
+ 海外 [板块/产品] 出货 X.XX 亿元（YoY +X%），主因 [出海 / 大客户突破]
- [板块/产品] 收入下滑 X%，主因 [需求疲软 / 行业降价]

α / β 归因：
α（公司层面）：[市占率提升 / 新品放量 / 海外突破]
β（行业层面）：[行业景气上行 / 政策催化 / 大宗下行带动毛利改善]
```

### Step 8：盈利质量穿透（A 股核心）

**净现比分析：**
- 经营性现金流 / 归母净利润 = 净现比
- 健康区间：0.8 - 1.5
- < 0.8：警示（账面盈利但现金未到账）
- > 1.5：可能预提了未来收入或集中收到应收

**扣非分析：**
- 扣非净利润 / 归母净利润 = 利润纯净度
- < 70%：非经常性损益占比过高，业绩可持续性存疑
- 重点穿透非经常性损益明细：政府补贴、投资收益、资产处置、公允价值变动、营业外收支

**应收 / 存货背离分析：**
- 应收账款增速 > 营收增速 → 预警（可能压货 / 信用放宽）
- 存货增速 > 营收增速 → 预警（需求疲软 / 渠道堆积）
