# A 股上市公司公告精读与智能筛选规范 (A-share Announcement Digest)

为散户与中小机构投资者构建的 **A 股公告快速理解工具**。解决"巨潮单日发布 1,500-3,000 份公告，90% 是模板化披露，散户被信息淹没"的核心痛点。

**人机协作模式**：E. 聚合-综合 —— AI 聚合多源公告 → 智能筛选 + 分类 → 结构化摘要 → 投资者按重要性快速消化。

**核心特征：**

- **覆盖范围**：巨潮资讯网 + 上交所 + 深交所互动易 + 北交所披露 4 大官方平台
- **响应时效**：模拟公告披露后 **24 小时内**（业绩公告 / 重大合同 / 减持 / 监管函等高时效场景 4-6 小时内）
- **目标用户**：散户、个人投资者、家族办公室、中小机构资管、信息过载的研究员
- **输出形式**：Markdown 摘要 + JSON 结构化数据（可选）
- **筛选率**：典型一天 1,500-3,000 份公告 → 经过滤后输出 5-20 条实质性公告
- **合规底线**：**禁止任何买卖建议**；所有判断必附公告链接；强制免责声明

## 核心执行要求

### 1. A 股法定 11 类公告分类标签 ⭐ 本土化强制要求

每条公告必须归到以下 **11 类标签** 之一（互斥分类，按重要性排序）：

| # | 标签 | 子类示例 | 投资者关注度 |
| :-: | :--- | :--- | :--- |
| 1 | **业绩相关** | 业绩预告 / 业绩快报 / 季报 / 半年报 / 年报 | ⭐⭐⭐⭐⭐ |
| 2 | **股东与减持** | 控股股东 / 5%+ 股东减持 / 增持 / 一致行动人变更 | ⭐⭐⭐⭐⭐ |
| 3 | **股权激励** | 限制性股票 / 股票期权 / 员工持股计划授予 / 解锁 / 注销 | ⭐⭐⭐⭐ |
| 4 | **重大合同** | 中标 / 框架协议 / 大额采购 / 海外订单（按营收 30% 起判定） | ⭐⭐⭐⭐ |
| 5 | **并购重组** | 重大资产重组 / 收购 / 出售资产 / 借壳 / 分拆 | ⭐⭐⭐⭐⭐ |
| 6 | **监管处罚** | 证监会立案 / 警示函 / 交易所问询函 / 行政处罚 / 公开谴责 | ⭐⭐⭐⭐⭐ |
| 7 | **涉诉与仲裁** | 重大诉讼 / 仲裁 / 执行 / 破产清算 | ⭐⭐⭐⭐ |
| 8 | **担保与抵押** | 对外担保 / 关联方担保 / 大额抵押 | ⭐⭐⭐ |
| 9 | **分红与回购** | 现金分红 / 送转 / 股份回购 / 回购注销 | ⭐⭐⭐⭐ |
| 10 | **股东大会 / 董事会决议** | 影响经营的实质决议（如增资 / 修改章程 / 高管变更） | ⭐⭐⭐ |
| 11 | **其他实质性公告** | 不能归入以上 10 类但有实质影响（如重大投资 / 资产减值 / 会计准则变更） | ⭐⭐⭐ |

**强制操作规范**：
- 每条公告必须标注**唯一标签**（不允许 2 个以上标签）
- 标签不在以上 11 类的公告，**判定为模板化噪音，直接剔除**
- 同一公司当日多份相关公告（如减持公告 + 简式权益变动书）需**合并为 1 条**摘要

### 2. 智能筛选规则 ⭐ 噪音过滤红线

**剔除清单（90% 公告属于这类）：**

| 公告类型 | 剔除理由 |
| :--- | :--- |
| 关于召开股东大会 / 董事会的通知 | 仅程序性，无实质影响 |
| 股东大会决议公告（仅议题通过未披露具体内容） | 内容已在前置公告披露 |
| 监事会决议公告（无重大事项） | 流于形式 |
| 独立董事候选人提名 / 高管简单变更（非核心高管） | 影响有限 |
| 关于会计师事务所聘任 / 续聘 | 常规程序 |
| 关于使用闲置自有资金购买理财产品 | 资金管理常规 |
| 公司章程修订（仅文字修订） | 程序性 |
| 投资者关系活动记录表（仅披露调研形式） | 实质内容已在投资者交流披露 |
| 关于召开业绩说明会的预告 | 通知性 |
| 关于股东减持计划进展（无新增减持） | 重复披露 |

**保留清单（10% 实质性公告）：**

- 业绩预告 / 业绩快报（已大额变动）
- 大股东 5%+ 减持计划与实施
- 股权激励授予与解锁条件
- 重大合同（中标金额 ≥ 上年营收 30%）
- 资产重组 / 并购 / 借壳
- 监管处罚 / 立案调查 / 警示函 / 问询函
- 控股股东股权质押率重大变动
- 重大诉讼 / 仲裁 / 执行
- 关联交易超过营收 5%
- 重大投资 / 募集资金用途变更
- 重大资产减值
- 重大对外担保 / 担保比例超净资产 50%

### 3. 利好 / 利空 / 中性判定标准

每条公告必须给出**性质判定**，用统一规范：

| 性质 | 判定依据 | 示例 |
| :--- | :--- | :--- |
| 🟢 **利好** | 直接增加营收 / 净利润 / 现金流；改善市场预期 | 大额中标 / 业绩超预期 / 实控人增持 / 利润分配 |
| 🔴 **利空** | 直接减少营收 / 净利润 / 现金流；恶化市场预期 | 业绩低于预期 / 监管处罚 / 大股东减持 / 商誉减值 |
| ⚪ **中性偏正** | 长期利好但短期影响有限 | 战略性收购 / 海外布局 / 募投项目立项 |
| ⚫ **中性偏负** | 长期风险但短期影响有限 | 资产质押率上升 / 部分高管变更 |
| ⚪ **中性** | 维持现状 / 难以判断 | 程序性事项 / 信息不足以判断 |

**判定红线**：
- **禁止**使用"重大利好""绝对利好"等绝对化表述
- **禁止**给出"建议买入""建议卖出"等操作建议
- **必须**说明判定依据（"因为 X 增加了 Y%"），不能仅给标签

### 4. 公告摘要标准结构（每条 ≤ 200 字）

**强制 6 段式**：

```
【标题】[公司简称]([代码]) [公告类型] - [一句话核心]
【日期】公告披露日 YYYY-MM-DD
【性质】🟢 利好 / 🔴 利空 / ⚪ 中性
【核心数据】X 项关键量化（金额、比例、时间窗）
【影响判断】对盈利 / 估值 / 短期股价的影响（≤80 字）
【原文出处】巨潮链接（点击可查阅原文）

[完整摘要正文 80-150 字，含背景 + 关键变化 + 已披露的下一步]
```

**示例**（业绩预告类）：
```
【标题】华明装备(002270.SZ) 业绩预告 - 2025 三季报预增 50.5%
【日期】2025-10-12
【性质】🟢 利好
【核心数据】预计前三季度归母 5.33-5.60 亿元（同比 +48.3-55.8%）；扣非 5.10-5.40 亿元（同比 +60-69%）
【影响判断】增速远超 2025H1（+34%），预告类型为"预增"，业绩弹性来自电力工程业务剥离 + 海外加速。下一步关注 10/27 三季报实际数字 vs 预告中枢
【原文出处】巨潮：[2025 年前三季度业绩预告] (http://www.cninfo.com.cn/...)
```

### 5. 实时性与可信度规范

**时效要求**：
- 业绩预告 / 业绩快报 / 监管函 / 立案调查公告：**4-6 小时**内完成摘要
- 大股东减持 / 重大合同 / 重组公告：**12 小时**内
- 其他实质性公告：**24 小时**内
- 模板化噪音：直接剔除，不输出

**可信度规范**：
- 所有摘要数字必须**直接引自公告原文**，不允许推算 / 估算
- 涉及历史数据对比时，必须标注历史数据出处（如"vs 2024 年同期"）
- 涉及业绩预告与一致预期对比时，必须说明 Wind / 同花顺 iFinD 一致预期取数日

### 6. 关联交叉验证 ⭐ A 股特色

A 股公告常存在"同一议题、多份公告"情况，必须做交叉验证：

| 议题类型 | 关联公告组合 | 交叉验证规则 |
| :--- | :--- | :--- |
| 大股东减持 | 减持计划预披露 + 简式权益变动书 + 减持完成 | 实际减持比例 / 价格区间 vs 预披露计划 |
| 业绩预告 | 业绩预告 + 业绩快报 + 正式财报 | 三方数字偏差 > 10% 必须解释 |
| 股权激励 | 激励计划草案 + 股东大会决议 + 授予公告 | 解锁条件实际达成情况 |
| 重大合同 | 中标公告 + 框架协议 + 合同签订 + 履约进展 | 合同从中标到收入确认的时间链 |
| 并购重组 | 重组预案 + 重组报告书 + 反馈意见 + 上会结果 | 估值、对价、业绩对赌条款一致性 |

### 7. 公告日股价反应数据

每条实质性公告应附**公告日 T+0 至 T+5 股价反应**（如能取得）：

```
公告日股价反应（数据源：同花顺 iFinD / Wind）
T+0（公告日）：开盘 / 收盘 / 涨跌幅 / 成交量 vs 前日均值
T+1 - T+5：累计涨跌幅 / 是否跑赢沪深 300
```

**用途**：让投资者直观看到市场对此类公告的真实反应，避免"理论利好实际却下跌"的认知偏差。

## 工作流 (High-Level Workflow)

### 阶段 1：公告采集与时效核查 (10-30 分钟)

**🚨 核心防御**：禁止依赖训练集中的旧公告数据

1. **核实当前日期**：明确写下今日年月日
2. **目标公告范围确认**：单公司 / 多公司 / 行业 / 全市场 / 时间窗
3. **数据源连接**：巨潮资讯网 → 上交所 → 深交所 → 北交所，按优先级抓取
4. **时效性验证**：公告日距今 < 3 个月（年报点评距今 < 6 个月）
5. **如无法实时抓取**：提示用户粘贴公告 PDF / 原文文本

### 阶段 2：智能筛选与分类 (10-20 分钟)

- 应用第 1 节 11 类标签分类
- 应用第 2 节剔除清单（90% 公告剔除）
- 同公司多公告合并（如减持计划 + 简式权益变动书）
- 输出待精读公告清单（典型 5-20 条）

### 阶段 3：逐条精读与摘要 (1-3 小时，视数量)

每条公告执行：
1. 阅读公告原文（注意：业绩预告必须区分 8 种法定类型；详见 [earnings-analysis-cn] §2.2）
2. 抽取核心数据 / 关键变化
3. 利好 / 利空 / 中性判定 + 理由
4. 影响判断（盈利 / 估值 / 短期股价）
5. 关联交叉验证（如有同议题历史公告）
6. 公告日股价反应数据（如能取得）
7. 按第 4 节标准 6 段式格式输出

### 阶段 4：A 股地雷扫描 (10-20 分钟)

应用第 10 节 10 项地雷信号清单，对所有精读公告做最后一遍扫描，输出地雷预警清单（独立段落）。

### 阶段 5：摘要汇总与合规质检 (10 分钟)

- 输出全部公告摘要
- 末尾附"今日重点关注 3 条"
- 强制免责声明
- 全部超链接验证（无死链）

详细分步指南详见 [references/workflow.md](references/workflow.md)。

| :--- | :--- |
| 归属于上市公司股东的净利润 | 归母净利润 |
| 扣除非经常性损益后的归属于上市公司股东的净利润 | 扣非净利润 / "剔除一次性收益后的真实利润" |
| 控股股东 | 大股东 / "公司实际控制人" |
| 一致行动人 | "和大股东共同行动的人" |
| 简式权益变动书 | "大股东减持 / 增持的正式通知" |
| 业绩预告类型 | 预增 / 略增 / 续盈 / 扭亏 / 首亏 / 续亏 / 预减 / 略减（A 股法定 8 种）|
| 商誉 | "公司过去并购时多付出的钱（未来可能减值）" |
| 关联交易 | "和大股东 / 高管控股的公司之间的交易" |

**禁止用语清单**：

- ❌ "重大利好" / "绝对利好" → ✅ "积极信号"
- ❌ "建议买入" / "建议卖出" → ✅ "本公告未对盈利产生直接影响 / 短期可能引发股价波动"
- ❌ "稳赚" / "肯定" / "必涨" → ✅ 量化分析 + 假设条件
- ❌ "强烈推荐" / "重点关注" → ✅ "值得跟踪" / "需进一步观察"

## 产出物最终交付技术规范

**核心交付成果**：Markdown 摘要文件（.md）

**规范文件命名**：`[公告主体]_[时间窗]_公告精读_CN.md`

**范例**：

- `华明装备_2026Q1_公告精读_CN.md`（单公司单期）

- `A股_2026-05-28_公告精读_CN.md`（全市场单日）
- `贵州茅台_2025-10_公告精读_CN.md`（单公司单月）

**输出结构**：

```markdown
# [公告主体] [时间窗] 公告精读

[3 条核心摘要]

[N 条详细摘要]

## 三、A 股特色地雷预警
[如有地雷信号]

## 四、本期公告汇总统计
- 共筛查公告 X 份
- 实质性公告 Y 条（保留率 Z%）
- 利好 / 利空 / 中性分布
- 11 类标签分布

## 五、参考资料及信息来源
[完整公告链接列表]

## 六、免责声明
[标准免责文本]
```
