# A 股证券研究行业综述报告规范 (A-share Sector Overview)

创建符合中国证券业协会《发布证券研究报告执业规范》及国内顶级券商（中信证券、中金公司、海通证券、国泰君安、华泰证券等）标准的 **A 股行业综述/产业链研究报告**，作为分析师对某一行业（或细分主题）的系统性研究输出。

**核心特征：**

- **报告篇幅**：20-30 页
- **字数规模**：6,000 - 10,000 字（深度中文产业研究术语）
- **核心表格**：3-5 张产业链拆解表 / 竞争格局表 / 政策事件表
- **动态图表**：12-18 张（行业景气度趋势、产业链占比、市占率、估值分位）
- **响应时效**：5-10 个工作日
- **目标受众**：公募基金行业研究员、私募投资经理、产业资本投资部门
- **核心聚焦**：行业 β（系统性机会）、产业链利润分配、政策红利兑现节奏
- **字体规范**：宋体 / 微软雅黑（中文），Arial / Times New Roman（英文与数字）
- **字号规范**：正文 10.5pt（五号）；一级标题 14-16pt 加粗；二级标题 12pt 加粗；表头 10pt；图注 9pt
