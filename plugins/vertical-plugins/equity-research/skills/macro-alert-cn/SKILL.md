# 中国宏观数据异动监控与资产联动解读规范 (China Macro Alert & Asset Linkage)

为散户、资产配置者、家族办公室等中小投资者构建的**宏观数据快速理解工具**。解决"宏观数据公布后通常 1-2 小时内股 / 债 / 商品 / 汇率四大类资产即出现联动反应，散户无法及时识别 + 理解 + 应对"的痛点。

**人机协作模式**：C. 异常-处置 —— AI 全量扫描 9 大宏观指标 → 自动判定异动 → 解读驱动因素 + 资产影响 → 用户据此审视持仓。

**核心特征：**

- **覆盖指标**：9 大中国核心宏观指标（详见第 1 节）
- **监测频率**：每月固定公布日 / 季度公布日，公布后 **2-6 小时**内输出异动报告
- **目标用户**：散户、个人投资者、家族办公室、中小机构资产配置岗、宏观研究新人
- **输出形式**：Markdown 异动报告 + JSON 结构化数据
- **核心红线**：**禁止预测货币政策具体操作**（如"下次降息时点 / 幅度"），仅做情景推演
- **合规底线**：所有判断标注数据源；强制免责声明

## 触发场景 (When to Use)

**适用场景：**

- "本月 PMI 数据出炉，帮我解读异动"
- "2026 年 4 月 CPI 同比 -0.3%，怎么看"
- "社融数据公布，对股债商品有什么影响"
- "M1 同比转正了，意味着什么"
- "工业增加值低于预期 1.2pp，资产联动怎么看"
- "进出口数据，怎么影响人民币汇率"
- "宏观九大指标当月异动汇总"

**严禁使用本技能的场景：**

- **预测下一期具体数据** → 仅做"如果 X 则 Y"情景推演，禁绝对预测
- **预测货币政策操作**（降息 / 降准 / 公开市场操作） → 仅做情景推演
- **个股推荐 / 行业推荐** → 仅给行业 / 板块的"宏观传导逻辑"，不给具体标的
- **外国宏观数据**（美国 CPI / 欧元区 PMI / 日本央行决议） → 触发海外宏观模板
- **微观财务数据**（单公司业绩） → 触发 [earnings-analysis-cn]
- **行业景气数据**（如光伏装机 / 半导体出货） → 触发 [sector-overview-cn]
- 用户要求"判断当前是牛市还是熊市" → 拒绝市场判断，仅描述当前指标位置

### 2. 三重异动检测规则 ⭐ 核心算法

每个指标必须按以下 3 条规则做异动判定：

#### 规则 1：偏离历史滚动均值 1σ
```
异动 = | 当期值 - 过去 12 个月滚动均值 | > 1 × 过去 12 个月标准差
```

#### 规则 2：偏离一致预期 0.5pp 以上
```
异动 = | 当期实际值 - Wind/iFinD 一致预期中值 | > 0.5 个百分点
```

#### 规则 3：连续 3 个月同向变动趋势
```
异动 = 当期与前两期同向变动（同正或同负），且累计变动幅度 > 阈值
（PMI/CPI 阈值 1.0pp / 社融阈值 5,000 亿 / 工业增加值阈值 2.0pp）
```

**判定逻辑**：触发任一规则即输出"异动"标签 + 触发的规则编号 + 量化数字。

### 3. 异动分级与紧急度

| 等级 | 触发条件 | 输出 |
| :-: | :--- | :--- |
| 🔴 重大异动 | 同时触发 ≥2 条规则；或单条规则偏离 ≥ 2σ | 立即输出独立报告 + 全资产影响推演 |
| 🟡 中度异动 | 触发 1 条规则；偏离 1σ - 2σ | 列入"本期异动指标"清单 |
| ⚪ 一般波动 | 未触发任一规则 | 仅作"本期数据快报"记录 |
| 🟢 趋势确认 | 连续 3 月同向变动但偏离不大 | 标注"趋势确认"标签 |

### 4. 驱动因素分析框架 ⭐ 解读核心

每个异动必须按 4 维分析驱动因素：

#### 4.1 季节性因素
- 春节 / 国庆等节假日效应
- 雨季 / 寒潮等天气因素
- 财政集中支付节奏（如年初 / 季末）

#### 4.2 政策因素
- 货币政策（降准 / 降息 / 公开市场操作）
- 财政政策（专项债发行 / 减税降费）
- 行业政策（房地产松绑 / 新能源补贴）

#### 4.3 结构性因素
- 长期人口结构（老龄化 / 城镇化）
- 产业结构（制造业占比 / 服务业升级）
- 出口结构（高新技术品出口占比）

#### 4.4 外部冲击
- 大宗商品价格（原油 / 铁矿石 / 铜）
- 国际经济周期（美国衰退 / 欧元区降息）
- 地缘政治（中美贸易 / 俄乌冲突 / 中东局势）

### 5. 资产联动传导路径分析 ⭐ 中国市场本土化

每个异动必须给出对四类资产的传导路径：

#### 5.1 A 股传导

| 异动方向 | 受益板块 | 受损板块 |
| :--- | :--- | :--- |
| PMI ↑（经济扩张） | 周期股（钢铁 / 煤炭 / 建材）/ 消费白马 | 防御股（公用事业 / 高股息） |
| PMI ↓（经济收缩） | 防御股 / 黄金 / 央企红利 | 周期股 / 顺周期消费 |
| CPI ↑（通胀） | 食品饮料 / 必选消费 / 上游资源 | 价格管制行业 / 利率敏感板块 |
| CPI ↓（通缩压力） | 政策受益板块 | 顺周期消费 |
| 社融 ↑（信用扩张） | 银行（息差）/ 地产 / 基建 | 防御股 |
| 社融 ↓（信用紧缩） | 防御股 / 高股息 | 地产 / 基建 / 信贷敏感行业 |
| M1 ↑（企业活跃） | 顺周期 / 周期股 / 龙头白马 | — |
| M1-M2 剪刀差缩小 | 顺周期上行 | — |

#### 5.2 国债 / 利率债传导

| 异动方向 | 利率走势 | 国债收益率 |
| :--- | :--- | :--- |
| PMI ↑ | 利率上行预期 | 收益率上行 |
| CPI / PPI ↓ | 通缩预期 / 降息可能 | 收益率下行 |
| 社融 ↑ | 信用扩张 / 流动性宽松 | 短端下行 / 长端上行 |
| M2 ↑ | 流动性宽松 | 收益率下行 |

#### 5.3 商品（黑色 / 有色 / 化工 / 农产品）传导

| 异动方向 | 受益商品 | 受损商品 |
| :--- | :--- | :--- |
| PMI 生产分项 ↑ | 工业品（螺纹钢 / 铜 / 铝）| 农产品 |
| 进口同比 ↑ | 原油 / 铁矿石 / 大豆 | — |
| 房地产投资 ↑ | 螺纹钢 / 水泥 / 玻璃 | — |
| 制造业投资 ↑ | 铜 / 铝 / 工程机械原材料 | — |

#### 5.4 人民币汇率传导

| 异动方向 | 离岸 / 在岸人民币 |
| :--- | :--- |
| 贸易顺差扩大 | 人民币升值压力 |
| 出口同比 ↑ | 人民币升值压力 |
| M2 ↑ / 利率下行 | 人民币贬值压力 |
| 中美利差走阔 | 人民币贬值压力 |

### 6. 历史相似情境对照 ⭐ 散户友好

每个重大异动必须找出**历史相似情境**（过去 5-10 年内 1-3 次类似异动），并描述：

```
本次异动：2026 年 4 月 CPI 同比 -0.3%

历史相似情境：
1. 2022 年 7 月 CPI 同比 +2.7%（与本次方向相反，仅做对比）
2. 2020 年 11 月 CPI 同比 -0.5%（与本次相似，下行幅度更大）
   → 当时 A 股表现：沪深 300 后 1 个月 -2.1% / 后 3 个月 +5.4%
   → 当时国债收益率：10 年期国债 1 个月内下行 12bp
   → 当时人民币汇率：贬值 0.3%
3. 2009 年 2 月 CPI 同比 -1.6%（金融危机后通缩）
```

**注意**：仅作对照参考，不构成未来预测；必须说明每次情境的**独特背景**（金融危机 / 疫情 / 产能过剩等）。

### 10. 长周期趋势确认机制

除单期异动外，必须监控**连续 3 个月同向变动**作为"趋势确认"信号：

| 趋势 | 触发条件 | 含义 |
| :--- | :--- | :--- |
| 经济扩张确认 | 连续 3 月 PMI > 50 + 工业增加值同比上升 | 经济周期上行 |
| 通缩压力确认 | 连续 3 月 PPI 负值 + CPI < 1% | 通缩风险 |

| 出口放缓确认 | 连续 3 月出口同比 < 0 | 外需走弱 |
| 内需复苏确认 | 连续 3 月社零同比加速 | 消费复苏 |

## 工作流 (High-Level Workflow)

### 阶段 1：数据采集与时效核查 (10-30 分钟)

1. **核实今日日期**：明确写下今日年月日
2. **目标指标范围确认**：单指标 / 多指标 / 月度汇总
3. **数据源连接**：按优先级抓取国家统计局 / 央行 / 海关总署
4. **取数完成验证**：当期数据必须在 24 小时内（最新公布日内）
5. **历史数据准备**：过去 12 个月滚动均值与标准差

### 阶段 2：三重异动检测 (10-20 分钟)

- 应用 3 条异动规则
- 异动分级（🔴/🟡/⚪/🟢）
- 输出本期异动指标清单

### 阶段 3：驱动因素与资产传导分析 (30-60 分钟)

- 按 4 维（季节 / 政策 / 结构 / 外部）分析驱动因素
- 给出对 A 股 / 国债 / 商品 / 汇率四类资产的传导路径
- 找出历史相似情境（2-3 个）

### 阶段 4：长周期趋势确认 (10 分钟)

应用第 10 节趋势确认机制，标注是否触发 5 大趋势信号。

### 阶段 5：报告生成与合规质检 (15-30 分钟)

- 按下方"产出物规范"输出 Markdown 报告
- 全部数据源链接验证
- 强制免责声明
- 检查无政策预测红线触发

详细分步指南详见 [references/workflow.md](references/workflow.md)。
