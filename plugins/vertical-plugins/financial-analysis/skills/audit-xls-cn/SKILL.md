# A 股数据审计与排错规范 (A-share Data Auditor)

构建覆盖**研报 / 财报 / Excel 模型**三类对象的质量审计能力，作为 Financial-Services-CN 的"质量守门员"。

**人机协作模式**：C. 异常-处置 —— AI 全量扫描 → 标记异常/冲突 → 人判断归因并决定处置。

**核心交付物**：分级审计报告（Markdown 格式），按严重等级排序，每条问题含位置 + 描述 + 修复建议。

### 1. 三表勾稽规则（CAS 准则）⭐ A 股核心审计

#### 1.1 资产负债表平衡
```
资产合计 = 负债合计 + 所有者权益合计
```
- 容忍误差：< 1 元（仅允许四舍五入）
- 超过 1 元报 🔴 严重

#### 1.2 利润表-资产负债表勾稽
```
未分配利润(期末) = 未分配利润(期初) + 归母净利润 - 分红 - 提取盈余公积
```
- 容忍误差：< 0.1% 营收
- 超过 0.1% 报 🟡 警告，超过 0.5% 报 🔴 严重

#### 1.3 现金流量表-资产负债表勾稽
```
现金及现金等价物净增加额 = 期末现金等价物 - 期初现金等价物
```
- 容忍误差：< 1 元
- 同时核查"经营活动现金流入"与"销售商品收到的现金 + 收到的其他与经营活动有关的现金"的勾稽

#### 1.4 利润表-现金流量表间接法勾稽
```
经营活动现金流量净额 ≈ 净利润 + 折旧摊销 + 减值 + 财务费用 - 营运资本增加 - 投资收益 ± 其他
```
- 间接法验证：现金流量表附注的间接法表 vs 直接法表必须一致

### 3. 研报数字一致性检查

- **正文 vs 表格**：同一数字（如营收）在不同段落 / 表格 / 图表中是否一致
- **货币单位一致性**：是否混用"亿元"/"百万元"/"万元"
- **百分点 vs 百分比**：毛利率"提升 3.8pct" vs "提升 3.8%"是否准确区分
- **同比环比标注**：YoY / QoQ / MoM 是否标注清晰
- **小数位数一致**：估值倍数保留 1 位 / 比率保留 1 位 / 金额保留 2 位

### 4. Excel 公式审计（继承 audit-xls 英文版能力）

- **硬编码识别**：公式中包含数字常量（非引用单元格）
- **循环引用**：单元格 A 引用 B、B 引用 A
- **错误值**：`#REF!` / `#DIV/0!` / `#N/A` / `#VALUE!`
- **范围错误**：SUM 函数遗漏某行 / 列
- **冻结窗口与隐藏列**：是否有故意隐藏的调整项
- **外部链接**：是否依赖未提供的外部文件

## 中国市场本土化深度内容 ⭐⭐⭐【强制填充段】

### 11 类 A 股地雷扫描详细规则（每类含触发规则 + 真实案例）

#### 类 1：商誉减值（年报洗澡最常见手段）
- **触发**：商誉 / 总资产 > 30% 且当期商誉减值 / 归母净利润 > 30%
- **A 股真实案例**：
  - **天神娱乐（002354.SZ）**：2018 年商誉减值 40.6 亿元，导致全年亏损 71.5 亿（前期商誉占总资产 70%+）
  - **众生药业（002317.SZ）**：2024 年商誉减值 10+ 亿
- **散户应对**：年报披露前 1-2 个月警惕；查商誉占比 > 30% 的公司

#### 类 2：控股股东高质押
- **触发**：控股股东质押率 > 70%
- **真实案例**：
  - **金一文化（002721.SZ）**：实控人质押率 99%，引发股价闪崩
  - **东方网络（002175.SZ）**：质押爆仓，实控人易主
- **散户应对**：查"权益变动"专栏，质押率 ≥70% 列入高危观察

#### 类 3：30 日内董监高减持
- **触发**：报告期前后 30 日内累计减持 ≥ 1%
- **真实案例**：
  - **海康威视（002415.SZ）**：实控人 6 个月内频繁减持引发股价持续承压
- **散户应对**：跟踪"股份减持"专栏

#### 类 4：合同负债大幅减少
- **触发**：合同负债环比 < -20%
- **真实案例**：
  - **某新能源公司**：连续 2 个季度合同负债下滑，下一季业绩不及预期
- **散户应对**：每季报核对合同负债环比

#### 类 5：非经常占比过高
- **触发**：非经常性损益 / 归母净利润 > 30%
- **真实案例**：
  - **某汽车公司**：2024 年靠政府补贴 + 资产处置撑利润，扣非净利润同比 -50%
- **散户应对**：必须分别看"归母"和"扣非"

#### 类 6：应收账款激增
- **触发**：应收账款增速 > 营收增速 + 50%
- **真实案例**：
  - **康得新（002450.SZ）**：应收账款连续高速增长，最终爆出 122 亿货币资金造假
- **散户应对**：营收增速 vs 应收账款增速差距 > 50%，警惕

#### 类 7：存货激增
- **触发**：存货增速 > 营收增速 + 50%
- **真实案例**：
  - **獐子岛（002069.SZ）**：存货 / 营收 异常高位，最终爆出"扇贝跑路"
- **散户应对**：存货周转天数异常上升超 50% 警惕

#### 类 8：审计意见非标
- **触发**：保留意见 / 无法表示意见 / 否定意见
- **真实案例**：
  - **康美药业（600518.SH）**：2018 年年报"保留意见"，最终爆出 300 亿货币资金造假
- **散户应对**：任何非"标准无保留意见"都是红线信号

#### 类 9：ST / *ST 标识
- **触发**：股票简称含 ST / *ST / 退市风险警示
- **真实案例**：
  - **乐视网（300104.SZ）**：连续 ST → *ST → 退市
- **散户应对**：ST 股本身就是高风险信号

#### 类 10：连续亏损
- **触发**：连续 2 年扣非净利润 < 0
- **真实案例**：
  - **某传统行业公司**：连续亏损 3 年，触发退市
- **散户应对**：扣非连续 2 年负值 → 退市风险

#### 类 11：关联交易超 5%
- **触发**：关联交易 / 营收 > 5%
- **真实案例**：
  - **某地产公司**：与控股股东关联交易占营收 30%，被市场质疑利润操纵
- **散户应对**：年报附注"关联交易"详查

### 50+ 禁止用语完整清单

#### 类别 1：绝对化承诺（≥10 条）
- 必然 / 一定 / 绝对 / 肯定 / 必涨 / 必跌
- 稳赚 / 保本 / 保收益 / 零风险
- 100% / 完全 / 永远

#### 类别 2：误导性比较（≥10 条）
- 行业第一（无客观数据支撑）
- 远超同行（无定量对比）
- 龙头地位（未量化市占率）
- 业内领先 / 业内顶尖
- 唯一 / 独家（无证据）

#### 类别 3：未来收益承诺（≥10 条）
- 收益率 X%（无明确假设）

### A 股真实造假案例库（用于规则映射）

### 与 compliance-watcher-cn 的协同（关键！）

`audit-xls-cn` 与 `compliance-watcher-cn` 是金融研究 / 资管业务的"双重质量门"：

| 维度 | audit-xls-cn | compliance-watcher-cn |
| :--- | :--- | :--- |
| 焦点 | 数字勾稽 + 公式正确 + A 股地雷 | 法规合规 + 监管要求匹配 |
| 用户 | 研究员自检 | 合规岗自检 |
| 规则 | 静态（CAS 准则）| 动态（每日更新法规）|
| 输出 | 错误清单 | 合规评分 |

**联合工作流**：
1. 研究员先用 audit-xls-cn 自检数字 / 公式 / A 股地雷
2. 再用 compliance-watcher-cn 自检合规话术 / 评级体系 / 免责声明
3. 双重通过后才能发布
