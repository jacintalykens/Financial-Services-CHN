# comps-cn — 最佳实践与质检清单

> ⚠️ **本文件为骨架占位**。主笔：邢邵楠。6/19 前完成主体，6/26 前定稿。

## 待补章节

1. **优秀 vs 劣质 A 股可比分析案例对比**
   - 推荐基线：中信 / 中金 / 海通的 IPO 估值报告
   - 优秀案例特征：筛选规则透明 / 一致预期对齐 / 统计分位完整 / 结论审慎
   - 劣质案例特征：行业归类错误 / 口径不一 / 未剔除 ST / 数据日期混乱

2. **可比分析常见错误**
   - 错误 1：用 GICS 而非申万行业（导致选到不可比公司）
   - 错误 2：未对齐一致预期截止日（不同公司用不同日期的预期）
   - 错误 3：未剔除 ST / *ST（估值异常拉低中位数）
   - 错误 4：未剔除新股次新股（缺乏可比基期）
   - 错误 5：多元化集团按主业之外的行业归类
   - 错误 6：A+H 标的同时算入 A 股池和港股池（双重计算）

3. **行业-估值方法选择的最佳实践**
   - 高 ROE 稳定型（消费 / 医药）→ PB-ROE 框架
   - 高成长（半导体 / 新能源）→ PEG
   - 现金牛（白酒 / 公用事业）→ 股息率
   - 周期股 → PB 历史分位

4. **质检清单**
   - [ ] 申万二级行业一致
   - [ ] 流通市值 ±50% 区间
   - [ ] 主营业务收入占比 ≥60% 一致
   - [ ] 已剔除 ST / *ST / 退市警示股
   - [ ] 已剔除上市 < 6 个月新股
   - [ ] 一致预期截止日一致
   - [ ] ≥5 家覆盖券商
   - [ ] 5 sheet 结构完整
   - [ ] 无硬编码
   - [ ] 公式可追溯
   - [ ] 单元格批注解释复杂公式
   - [ ] Cover 含免责声明

## 验收标准

- 案例对比 ≥ 3 组
- 常见错误 ≥ 10 条
- 质检清单 ≥ 15 项
