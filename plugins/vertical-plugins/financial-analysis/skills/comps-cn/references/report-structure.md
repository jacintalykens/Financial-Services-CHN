## 待补章节

1. **5 sheet 详细模板**
   - **Cover**：标题 / 目标公司 / 日期 / 分析师 / 免责
   - **Assumptions**：5 条筛选规则 + 一致预期截止日 + 特殊调整说明
   - **Raw Data**：每列结构（公司代码 / 简称 / 申万二级 / 流通市值 / 8 大指标 × 3 档 = 24 列）
   - **Valuation Matrix**：估值矩阵布局 + 单元格公式
   - **Stats & Conclusion**：5 档统计 + 目标公司位置高亮 + 结论文本

2. **格式规范**
   - 表头颜色：券商深蓝（RGB 0,32,96）
   - 数字字体：Arial 9pt
   - 中文字体：微软雅黑 10pt
   - 金额单位：亿元保留 2 位
   - 比率单位：% 保留 1 位
   - 倍数单位：保留 1 位

3. **openpyxl 完整代码模板**（李苏润提供基础版，主笔补字段映射）

4. **行业-估值方法映射表**
   - 消费 → PE-Band
   - 银行 → PB + ROE + 股息率
   - 保险 → P/EV + PB
   - 地产 → NAV + PB
   - 未盈利成长股 → PS + EV/Sales
   - 周期股 → PB 历史分位 + EV/Capacity
