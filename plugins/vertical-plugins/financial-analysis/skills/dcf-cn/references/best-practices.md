2. **A 股 DCF 常见错误**
   - 错误 1：直接套美股 ERP（导致 WACC 偏低，估值虚高）
   - 错误 2：用日度 β（噪声太大，应用周度或月度）
   - 错误 3：永续增长率 g > Rf（违反金融逻辑，价值无穷大）
   - 错误 4：永续增长率 g 取 5%+（高于中国长期 GDP 名义增速上限）
   - 错误 5：忽略股权激励费用（科创板 / 创业板高研发公司 FCFF 严重失真）
   - 错误 6：忽略高新技术企业税率优惠（多数 TMT 公司适用 15%）
   - 错误 7：直接用账面 D/E 而非市值 D/E
   - 错误 8：未做敏感性分析（单点估值缺乏稳健性）

3. **DCF 与相对估值的交叉验证**
   - DCF 中枢 vs comps-cn 中位数对比
   - 偏离 >30% 必须解释原因（特殊护城河 / 周期位置 / 一次性事件）

4. **何时不用 DCF**（重要！）
   - 银行 → DDM
   - 保险 → P/EV
   - 地产 → NAV
   - 强周期 → PB 历史分位
   - 未盈利成长股 → PS-Band

5. **质检清单**
   - [ ] Rf 用中国 10 年国债
   - [ ] ERP 用沪深 300 历史
   - [ ] β 用周度回归
   - [ ] 已核查高新技术企业税率
   - [ ] g < Rf
   - [ ] g 在 1.5%-3.5%
   - [ ] 6 sheet 齐全
   - [ ] Assumptions 所有假设留痕
   - [ ] 含 WACC × g 敏感性
   - [ ] 含三档情景目标价
   - [ ] 无硬编码
   - [ ] 与 comps-cn 交叉验证
