# A 股 DCF 贴现现金流估值规范 (A-share DCF Valuation)

构建符合中国会计准则（CAS）与 A 股市场参数的 **DCF 估值模型**（Excel 工作簿），用于：

- 首次覆盖报告的绝对估值章节
- 业绩点评的目标价修正
- 投委会的内在价值评估
- IPO / 定增的价格论证

**核心交付物**：完整 .xlsx 文件（6 个 sheet：Assumptions / Income Statement / Cash Flow / WACC / DCF / Sensitivity）。

---

## 触发场景 (When to Use)

**适用场景：**

- "做一份宁德时代的 DCF 估值模型"
- "测算贵州茅台的内在价值"
- "对华明装备做 DCF + 敏感性分析"

**严禁使用本技能的场景：**

- **未盈利成长股**（科创板未盈利新股、亏损创业板公司）→ 触发 PS-Band 估值法
- **金融股**（银行 / 保险 / 券商）→ DCF 不适用，触发 DDM / 内含价值法 / PB-ROE
- **地产股**（万科 / 保利 / 招商蛇口）→ 触发 NAV（重估净资产）法
- **强周期股**（钢铁 / 煤炭 / 化工）→ DCF 不稳定，触发历史 PB 分位 + 行业景气位置
- 用户请求**相对估值** → 触发 [comps-cn]
- 用户请求**美股 DCF** → 触发英文 dcf-model

### 1. WACC 参数中国本土化 ⭐ 与英文 DCF 的最大区别

**强制要求**：所有 WACC 输入参数必须取自中国市场，不允许直接套用美股参数。

#### 1.1 无风险利率（Rf）
- **取数**：10 年期中国国债收益率（不用美债！）
- **数据源**：中国债券信息网（www.chinabond.com.cn）/ Wind 代码 S0059749
- **更新频率**：每个交易日
- **典型区间**：近 5 年 2.5% – 3.5%

#### 1.2 市场风险溢价（ERP）
- **取数**：沪深 300 指数近 10 年滚动年化收益 − 同期 10 年期国债收益
- **典型区间**：A 股近 10 年 ERP 约 5%-8%
- **数据源**：Wind 沪深 300 全收益指数 / iFinD
- **TODO**：胡佳宇补 ERP 测算口径（算术平均 vs 几何平均，10 年 vs 20 年）

#### 1.3 β 系数
- **取数**：Wind / Choice 的 60 周回归 β（不用日度，噪声太大）
- **基准指数**：沪深 300（默认）/ 中证 500（中小盘）/ 中证 1000（小盘）/ 北证 50（北交所）
- **行业 β 修正**：若公司 β 与申万行业 β 偏离 >30%，使用行业 β 加权

#### 1.4 实际所得税率（T）
- **标准税率**：25%
- **高新技术企业**：15%（需核查公司"高新技术企业认定"是否在有效期，每 3 年复审）
- **西部大开发企业**：15%
- **集成电路 / 软件企业**：减免税期内可低至 0%-12.5%
- **TODO**：核查税率的操作步骤（财报附注"所得税费用" + 巨潮"高新技术企业认定证书"公告）

#### 1.5 资本结构（D/E）
- **取数**：A 股财报披露的"有息负债 / 净资产"
- **市场化调整**：若公司有上市权益（市净率 PB > 1），用市值 E 替代账面 E

#### 1.6 债务成本（Kd）
- **取数**：财报"利息费用 / 平均带息负债"
- **市场化对标**：同评级 5 年期信用债到期收益率（中诚信 / 联合资信评级）

### 2. FCFF 计算（CAS 准则口径）⭐ 与 IFRS / GAAP 的差异点

**标准 FCFF 公式**（CAS 口径）：

```
FCFF = EBIT × (1 - T) + 折旧与摊销 - 资本开支 - 营运资本增加
```

**A 股准则细节**：

- **EBIT**：营业利润 + 财务费用（不含汇兑） − 投资收益（仅经常性投资收益保留，处置类剔除）
- **折旧与摊销**：CAS 不允许商誉摊销（与 IFRS 一致）；无形资产摊销保留
- **资本开支**：现金流量表"购建固定资产、无形资产和其他长期资产支付的现金"
- **营运资本**：（应收账款 + 应收票据 + 存货 + 合同资产）− （应付账款 + 应付票据 + 合同负债）
- **股权激励处理**：股份支付费用属于非现金支出，加回（参考 earnings-analysis-cn 第 3.2 节）

### 3. 预测期与永续期划分

#### 3.1 明确预测期（5-10 年）
- 默认 5 年（与一致预期重合度高的标的）
- 若公司处于高成长期（年营收增速 >30%），可延长至 7-10 年
- 每年必须明确：营收增速、毛利率、销售费用率、管理费用率、研发费用率、税率、营运资本占比、Capex/Sales

#### 3.2 永续增长率（g）
- **默认值**：2.5%（参考中国长期 GDP 实际增速 2-3% + 长期 CPI 2% → 名义 4-5% 上限）
- **下限**：1.5%（成熟行业 / 弱周期）
- **上限**：3.5%（人口红利退去后，3.5% 已是较激进假设）
- **严禁**：g > 长期 Rf（违反金融逻辑，会导致价值无穷大）

### 4. 敏感性分析 ⭐ 强制输出

必须输出二维敏感性分析表：**WACC × g** → 内在价值/股

```
            g=1.5%   g=2.0%   g=2.5%   g=3.0%   g=3.5%
WACC=7%      ...      ...      ...      ...      ...
WACC=8%      ...      ...      ...      ...      ...
WACC=9%      ...      ...      ...      ...      ...
WACC=10%     ...      ...      ...      ...      ...
WACC=11%     ...      ...      ...      ...      ...
```

**附加敏感性**（可选）：

- **营收增速** × **毛利率** → 5 年 EBIT
- **Capex/Sales** × **营运资本/Sales** → 5 年 FCFF

### 5. Excel 工作簿结构 ⭐ 硬性输出规范

输出 .xlsx 必须包含且仅包含以下 6 个 sheet（顺序固定）：

1. **Assumptions**：所有关键假设集中页（颜色：蓝色单元格 = 输入项，黑色 = 公式）
2. **Income Statement**：历史 5 年 + 预测 5-10 年利润表
3. **Cash Flow**：历史 5 年 + 预测 5-10 年现金流量表，含 FCFF 推导
4. **WACC**：WACC 测算页（含 Rf / ERP / β / T / D/E / Kd 所有输入与公式）
5. **DCF**：明确预测期贴现 + 终值（Gordon Growth）+ 内在价值/股
6. **Sensitivity**：WACC × g 敏感性表 + 三档情景（乐观 / 中性 / 悲观）目标价

**格式规范**：

- 假设单元格：蓝色字体（RGB 0,0,255），用户可修改
- 公式单元格：黑色字体，禁止硬编码
- 高亮：内在价值/股 与 当前股价 用条件格式高亮（绿色 = 低估 / 红色 = 高估）
- 所有金额单位以"百万元"或"亿元"统一，sheet 顶部明确标注

### 阶段 1：可行性核查（30 分钟）
- 确认公司适用 DCF（非银行 / 非保险 / 非地产 / 非纯周期 / 有正经营性现金流 ≥3 年）
- 若不适用，建议用户切换 [comps-cn] 或行业专用估值

### 阶段 2：历史财务数据入库（1-2 小时）
- 历史 5 年三张表入库
- 计算历史 FCFF（验证模型逻辑）

### 阶段 3：WACC 测算（30-60 分钟）
- 拉 10 年期国债 / 沪深 300 / β / 高新技术企业认定
- 输出 WACC 中枢值（典型 A 股区间 7%-10%）

### 阶段 4：预测期建模（2-4 小时）
- 营收按业务线分别预测
- 毛利率 / 费用率假设需在 Assumptions 页留痕
- 永续增长率取值并说明理由

### 阶段 5：敏感性分析与结论（30 分钟）
- WACC × g 二维表
- 三档情景目标价
- 一句话内在价值 vs 当前股价对比

### 阶段 6：自检（30 分钟）
- 跑 [audit-xls-cn](../audit-xls-cn/) 检查公式正确性、勾稽关系

### 5 个典型行业 FCFF 测算示例

#### 1. 消费行业（贵州茅台 类）
- **EBIT 计算**：营业利润 + 财务费用（基本为 0，无大额负债）
- **折旧摊销**：低（资本开支轻）
- **资本开支**：低 / 营收（建产能 5-8%）
- **营运资本变动**：通常为正（库存与应收增长）
- **特殊项**：高分红率 70%+
- **典型 FCFF / 净利润**：80-90%

#### 2. 制造行业（宁德时代 类）
- **EBIT 计算**：营业利润 + 财务费用
- **折旧摊销**：高（重资产）
- **资本开支**：高 / 营收（产能扩张 15-25%）
- **营运资本变动**：正（应收 + 存货持续增长）
- **特殊项**：股权激励费用大额，需加回
- **典型 FCFF / 净利润**：40-60%

#### 3. 医药行业（恒瑞医药 类）
- **EBIT 计算**：营业利润（核心）
- **折旧摊销**：中（仪器设备）
- **资本开支**：中等（5-10%）
- **研发投入资本化**：常见
- **特殊项**：商誉与研发资本化处理需透明
- **典型 FCFF / 净利润**：60-75%

#### 4. TMT 行业（中际旭创 类）
- **EBIT 计算**：营业利润 + 财务费用
- **折旧摊销**：中等
- **资本开支**：随产业周期波动
- **股权激励费用**：大额（创业板高新企业）
- **特殊项**：客户集中度高，回款波动
- **典型 FCFF / 净利润**：50-70%

#### 5. 周期行业（万华化学 类）
- **EBIT 计算**：受产品价格影响极大
- **折旧摊销**：高（重资产）
- **资本开支**：周期性（向上时大量扩张）
- **营运资本变动**：剧烈
- **DCF 适用性**：弱，建议改用 PB 历史分位
- **典型 FCFF / 净利润**：波动极大

### A 股 DCF 10 大常见错误清单

| 错误 | 描述 | 修复 |
| :--- | :--- | :--- |
| 1. 直接套用美股 ERP | 用美股 5% ERP 算 A 股 | 改用沪深 300 10 年滚动 |
| 2. 用日度 β | 日度 β 噪声太大 | 改用 60 周回归 |
| 3. 永续 g > Rf | 违反金融逻辑，价值无穷大 | g 必须 < Rf |
| 4. 永续 g 取 5%+ | 高于中国长期 GDP 名义增速 | 上限 3.5% |
| 5. 忽略股权激励费用 | 创业板 / 科创板严重失真 | 加回非现金股权支付 |
| 6. 忽略高新技术企业税率 | 多数 TMT 公司适用 15% | 核查认证有效期 |
| 7. 用账面 D/E 而非市值 D/E | 高估市净率公司的权重 | 用市值口径 |
| 8. 未做敏感性分析 | 单点估值缺乏稳健性 | 必须 WACC × g 二维表 |
| 9. 用美元口径而非人民币 | 跨境标的失真 | A 股标的统一人民币 |
| 10. 永续期增长率高于明确期 | 不符合"成长-成熟-稳定"逻辑 | 永续期必须 ≤ 明确期末年 |

### 何时不用 DCF（行业适用性详表）

| 行业 | 是否适用 DCF | 应改用 |
| :--- | :--- | :--- |
| 银行 | ❌ | DDM / PB-ROE |
| 保险 | ❌ | P/EV（市值 / 内含价值） |
| 券商 | ❌ | PB / PE 顺周期 |
| 地产 | ❌ | NAV 重估 |
| 强周期股（钢铁/煤炭/化工） | ⚠️ 不稳 | PB 历史分位 + 行业景气位置 |
| 未盈利成长股（科创板 / 创业板新股） | ❌ | PS-Band / EV/Sales |
| 高 ROE 稳定（白酒 / 医药白马） | ✅ 适合 | DCF + PB-ROE |
| 制造业（新能源 / 设备） | ✅ 适合 | DCF + PE-Band |
| 医药 / 消费 / 公用事业 | ✅ 适合 | DCF + PE-Band |
| TMT（已盈利） | ✅ 适合（谨慎） | DCF + PEG |

### 与 comps-cn 双锚交叉验证规范

A 股顶级研报必须做 **DCF + Comps 双锚交叉验证**：

```
1. DCF 中性目标价 = X 元
2. Comps 中性目标价 = Y 元
3. 偏离度 = |X - Y| / max(X, Y)

判定：
- 偏离度 < 15% → 可信，双法相互验证
- 偏离度 15-30% → 需查明原因（特殊护城河 / 周期位置 / 一次性事件）
- 偏离度 > 30% → 严重不一致，必须重新审视假设
```
