# 跨境监管函件翻译与合规风险解读规范 (Cross-border Regulatory Translation & Compliance)

为中国出海企业、中小机构法务、跨境业务负责人构建的**跨境监管沟通桥梁工具**。解决"普通翻译软件不懂金融监管语境、跨境律所翻译 800-2000 元/页、企业无法判断函件紧急度和正确响应"的核心痛点。

**人机协作模式**：A. 起草-审核 —— AI 完整解读函件 → 输出双语对照 + 风险摘要 + 行动建议 → 人确认后联系当地律师做正式回复。

**核心特征：**

- **覆盖监管来源**：美国 / 英国 / 香港 / 新加坡 / 欧盟 / 日本 / 澳大利亚 7 大主要监管体系
- **响应时效**：30-60 分钟（中等长度监管函）
- **目标用户**：出海企业法务、中小机构跨境业务、个人投资者跨境账户、出海企业 CEO / CFO
- **行业聚焦**：金融（券商 / 资管 / 跨境支付）、TMT（科技 / 互联网 / 数据出海）、新能源（电池 / 整车 / 光伏出海）
- **核心红线**：**禁止替用户回复 / 禁止声称具法律效力 / 必须建议咨询当地持牌律师**

## 触发场景 (When to Use)

**适用场景：**

- "收到 SEC 关于信息披露的问询函，帮我解读"
- "公司在英国子公司收到 FCA 警告信，看懂措辞紧急度"
- "美国 CFIUS 对我们投资的审查通知，怎么回应"
- "香港证监会 SFC 关于反洗钱 (AML) 的检查通知"
- "新加坡 MAS 关于跨境支付牌照的合规要求"
- "OFAC 关于实体清单的合规风险提示"
- "欧盟 GDPR 数据保护的合规审查函"

**严禁使用本技能的场景：**

- **代企业回复监管函** → 必须由当地持牌律师起草正式回复
- **境内监管沟通** → 触发 [compliance-watcher-cn]
- **个人收到的境外法院传票 / 诉讼文书** → 紧急建议咨询当地诉讼律师
- **税务函件**（IRS / HMRC 等） → 跨境税务有专属规则，建议触发跨境税务专用模板
- **签证 / 移民相关** → 不适用
- 用户上传非监管函件（如行业研究 / 营销材料） → 拒绝处理

### 2. 监管函件紧急度判定标准 ⭐ 核心方法论

每份函件必须按以下 4 档紧急度判定：

#### 🔴 极度紧急（24-48 小时响应）
- **关键词**：Subpoena / Investigation Notice / Cease and Desist / Penalty Determination / Final Notice / Wells Notice
- **特征**：明确法律程序、明确金额、明确诉讼 / 处罚意图
- **行动**：立即联系当地律师 + 通知公司董事会 + 准备应诉团队

#### 🟡 紧急（5-10 工作日响应）
- **关键词**：Information Request / Subpoena Issued / Inquiry Letter / Compliance Notice
- **特征**：要求提供文件 / 信息 / 解释，但未明确处罚
- **行动**：联系当地律师 + 启动内部合规调查 + 在期限内回复

#### ⚪ 普通（15-30 日响应）
- **关键词**：Comment Letter / Review Notice / Routine Examination
- **特征**：常规审查 / 评论性问询
- **行动**：内部初步评估 + 联系律师审阅 + 在期限内回复

#### ⚫ 信息性（无须立即响应）
- **关键词**：Notice of New Regulation / FAQ Update / Industry Guidance
- **特征**：仅告知监管变化或行业指引
- **行动**：内部合规更新 + 评估是否影响业务

### 3. 双语对照翻译规范 ⭐ 输出核心

每段原文必须输出**精确翻译 + 风险注释**三栏对照：

```
原文（英文）：
"The Staff has reviewed your Form 10-K and has the following comments. 
Please respond to the comments within thirty (30) days of the date of 
this letter."

中文翻译（精准法律语境）：
"工作人员已审阅贵公司提交的 Form 10-K 文件，并提出以下评论。请贵公司
在收到本函件之日起 30 天内回复。"

风险注释：
- 这是 SEC 评论函（Comment Letter），属于 ⚪ 普通紧急度
- 30 天回复期限是 SEC 标准要求，逾期可能升级为更严厉的监管措施
- "评论"意味着 SEC 工作人员对披露内容有疑问，需提供澄清或修改
- 主要影响：可能要求修订 10-K 文件、补充披露、影响后续 SEC 注册
- 建议行动：联系美国证券律师审阅评论内容，准备 30 天内的正式书面回复
- 历史案例：2024 年 XX 中概股因 Form 10-K 评论函未及时回复，被升级为正式调查
```

### 4. 法规背景补充（散户友好性核心）

每份函件必须补充以下**法规背景**：

#### 4.1 监管机构权限范围
- 该监管机构能做什么 / 不能做什么
- 与中国监管的对应关系（如 SEC ≈ 中国证监会，但权限不同）

#### 4.2 典型流程
- 该类函件的标准处理流程（如 SEC Comment Letter 标准流程：发送 → 回复 → 二次评论 → 完成）
- 各阶段的法定时限

#### 4.3 历史处罚案例
- 引用该监管机构对类似中国公司的处罚（公开信息）
- 处罚原因 / 金额 / 后续影响
- 帮助用户判断本次函件的严重程度

### 5. 建议行动清单（操作性指引）⭐ 强制输出

每份审查报告必须输出**优先级排序的行动清单**：

```
🔴 立即行动（24 小时内）：
1. 联系当地持牌律师（推荐律所：XX、XX、XX，专注 SEC 监管事务）
2. 通知公司董事会 / 法务部门
3. 收集函件涉及的全部历史文件，准备律师评审
4. 评估是否需要发布信息披露（对上市公司）

🟡 短期行动（1 周内）：
5. 与律师初步评估应对策略
6. 启动内部合规审查
7. 评估是否需要主动披露 / 与监管机构对话
8. 评估对业务运营 / 跨境结算 / 牌照的影响

⚪ 中期行动（30 天内）：
9. 在期限内提交正式回复
10. 启动合规整改（如适用）
11. 评估是否需要更新内部合规手册 / 流程

📌 长期跟踪：
12. 跟踪监管机构后续反应
13. 持续监测同类型监管动态（建议结合 [compliance-watcher-cn]）
```

### 6. 核心红线（必须遵守）⭐⭐⭐【硬性强制】

#### 6.1 禁止行为
- ❌ **禁止替用户起草正式回复**（即使用户要求）
- ❌ **禁止声称"具有法律效力"**
- ❌ **禁止保证"按此回复一定能解决"**
- ❌ **禁止泄露监管函件内容**
- ❌ **禁止预测监管处罚具体结果**（金额 / 时长）

#### 6.2 必须行为
- ✅ **必须建议咨询当地持牌律师**（每份报告至少 2-3 次提及）
- ✅ **必须强调"双语对照仅作理解辅助"**
- ✅ **必须建议保留函件原文作为正式参照**
- ✅ **必须说明"任何法律决策应基于律师的正式意见"**

#### 6.3 标准免责声明

```
本翻译与解读仅作为理解辅助，不构成法律意见。

1. 本工具不具有法律效力，任何法律决策应基于当地持牌律师的正式意见。
2. 本工具不能代替企业向监管机构提交正式回复 / 文件。
3. 实际响应监管函件时，必须以原文为准，本中文翻译仅供企业内部理解。
4. 本工具不对因依赖本翻译与解读而产生的任何法律 / 商业 / 财务损失承担责任。
5. 跨境监管沟通涉及高度专业的法律 / 监管知识，强烈建议咨询当地持牌律师。

[当地推荐律所联系方式：详见'建议行动清单']
```

## 工作流 (High-Level Workflow)

### 阶段 1：函件接收与监管来源识别 (10 分钟)

1. 接收函件 PDF / 文本
2. 识别监管机构（SEC / FCA / SFC / 等 7 大体系）
3. 识别函件类型（Subpoena / Comment Letter / Notice / etc.）
4. 识别紧急度（🔴/🟡/⚪/⚫ 4 档）
5. 识别行业（金融 / TMT / 新能源 / 其他）

### 阶段 2：双语对照精准翻译 (20-30 分钟)

按段落或条款进行精准翻译：
1. 原文（保留格式）
2. 中文翻译（金融法律精准语境）
3. 风险注释（每段 50-100 字）

### 阶段 3：法规背景补充 (15-20 分钟)

- 监管机构权限范围
- 该类函件的典型流程
- 历史相似案例（2-3 个）

### 阶段 4：建议行动清单生成 (10-15 分钟)

按 🔴/🟡/⚪/📌 4 档紧急度，生成行动清单。

### 阶段 5：报告生成与合规质检 (10 分钟)

- 按下方规范输出 Markdown 报告
- 强制免责声明
- 提示用户"联系当地律师"

详细分步指南详见 [references/workflow.md](references/workflow.md)。

## 关键术语规范化清单 ⭐ 强制术语规范

详见第 8 节"法律术语对照表"。

**禁止用语清单**：

- ❌ "根据本翻译，您应该立即支付罚款" → ✅ "本函件提及罚款金额 X，建议律师审阅后正式回复"
- ❌ "翻译完毕，可以按中文版直接回复" → ✅ "本中文版仅供理解辅助，正式回复必须基于原文 + 律师起草"
- ❌ "建议尽快咨询律师" → ✅ "立即联系当地持牌律师（联系建议见下方）"

## 产出物最终交付技术规范

**核心交付成果**：Markdown 双语审查报告（.md）

**规范文件命名**：`[公司简称]_[监管机构]_[函件类型]_审查报告_CN_[YYYYMMDD].md`

**范例**：

- `中概股A_SEC_Comment_Letter_审查报告_CN_20260530.md`
- `XX跨境支付_OFAC_Inquiry_审查报告_CN_20260530.md`
- `XX新能源_DOC_Anti-Dumping_审查报告_CN_20260530.md`

**输出结构**：

```markdown
# [公司简称][监管机构][函件类型]审查报告

## 一、紧急度评估

- 建议响应时限：X 工作日内
- 关键风险：[一句话]

## 二、函件基础信息
- 监管机构 / 函件编号 / 函件日期 / 回复期限

## 三、双语对照精准翻译
[逐段三栏对照]

## 四、监管机构背景补充
- 权限范围
- 典型流程
- 历史相似案例

## 五、建议行动清单
- 🔴 立即行动（24 小时内）
- 🟡 短期行动（1 周内）
- ⚪ 中期行动（30 天内）
- 📌 长期跟踪

## 六、当地律所联系建议
[律所类型 + 平均费率，不指定具体律所]

## 七、参考资料
[监管机构官网链接 + 相关法规]

## 八、免责声明与合规警示
[标准免责文本]
```
